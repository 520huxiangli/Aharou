# Aharou 自建依赖索引的坐标清单（group:artifact，每行一条，# 开头为注释）
#
# 这份清单决定离线索引覆盖哪些坐标。收录标准：
#   1. Google Maven（maven.google.com）在国内不可达，androidx.* / com.google.* 优先收录；
#   2. Android 项目里高频出现（模板默认依赖、常见第三方库）；
#   3. 单条抓取失败不影响其它条（同步脚本逐条容错）。
#
# 注意：清单外的坐标查不到是正常的——这是兜底源，不是完整镜像。
# 由 scripts/sync-maven-index.py 消费，产出 maven-index.json.gz 传到 cnb release。

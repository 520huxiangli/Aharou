# 验收用例：宿主设备管理（`host-device-admin`）

## 应该触发

- 「帮我把这个 apk 装上」
- 「抓一下日志」
- 「卸掉那个应用」
- 「读一下 /sdcard 里那个文件」

## 不该触发

- 「改一下这个文件的第十行」—— 容器内文件操作，走文件工具就行
- 「搜一下代码里的这个函数」—— 容器里有 `rg`，别绕道 Shizuku

## 验收点

- [ ] 系统级操作走 `Shizuku`，且**没有把 Shizuku 当容器用**（它没有 `rg` / `py` / `node`，也没有工作区目录）
- [ ] 用户给的包名 / 文件名没有直接拼进 shell（命令注入），带空格引号的路径做了转义
- [ ] 卸应用、改系统设置、`pm clear`（清数据）这类不可逆或影响大的操作，先说明再执行
- [ ] 一段流程做完把中间产物清掉（`/sdcard` 上的临时日志、截图）
- [ ] 需要装 APK 时先把文件弄到容器能读的位置，没有直接让 `pm install` 去读 `/sdcard`

## 怎么手工验

让它装一个测试 APK，看它是不是先准备文件、再以 shell 身份安装；完成后检查 `/sdcard` 上有没有留下临时文件。

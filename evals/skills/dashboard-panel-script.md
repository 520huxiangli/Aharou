# 验收用例：面板脚本编写（`dashboard-panel-script`）

## 应该触发

- 「做个面板看余额」
- 「这个卡片怎么不刷新」
- 「面板脚本报错了」

## 不该触发

- 「帮我看下余额」—— 那是查数据，不是写面板
- 「给我算一下这个月的费用」—— 一次性计算，不需要写面板脚本

## 验收点

- [ ] 脚本 stdout **只有 JSON**，调试信息走 stderr，且 `json.dumps(..., ensure_ascii=False)`
- [ ] 算比率 / 费用前先判零，没有除零崩掉
- [ ] 拿不到数据时输出一张带 `StatusDot(color="Attention")` 的卡片说明情况，而不是让脚本抛错、面板整块挂掉
- [ ] `compact` 保持单行精炼（状态点 + 关键指标），没有塞长文本
- [ ] 用的是注入的环境变量（`AICODE_*`），没有把 API Key 硬编码进脚本

## 怎么手工验

写一个面板脚本，故意让它拿不到数据（比如填个错的 key），看它是不是输出一张「说明情况」的卡片而不是报错；再确认展开态显示正常。

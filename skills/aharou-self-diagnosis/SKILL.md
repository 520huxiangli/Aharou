# Aharou 自身故障排查

## 第一步：按现象定性，别一上来就翻日志

| 现象 | 去哪查 |
| --- | --- |
| App 崩了、闪退 | 崩溃错误页 / 崩溃日志 |
| AI 请求失败、反复重试 | 重试气泡上的失败原因 + HTTP 状态码 |
| 发热、卡顿、掉电 | 设置 → 数据与诊断 → 性能分析 |
| 容器里命令报错、下载失败 | 容器环境体检 |
| 连不上服务器 | 对话页顶部的 SSH 状态 |
| 会话卡住不动、像是在等什么 | 侧边栏指示灯（橙色＝在等你授权） |

## 读日志

- 文件目录：`/storage/emulated/0/Android/data/com.aharou.agent/files/logs/`。
  注意：`.debug` / `.beta` 构建的包名带后缀，目录名随之变成 `com.aharou.agent.debug` / `.beta`，先确认用户装的是哪个包。
- 容器里默认看不到这个目录（除非用户挂了 `/sdcard`）。用 `Shizuku` 工具以 adb shell 身份读：先 `ls <日志目录>` 看有哪些日期文件，再 `cat` 目标文件。
- 应用内也能看（设置 → 日志）：默认定位今天，等级可在 Verbose/Debug/Info/Warn/Error/None 之间切。正式版默认 `Info`，查 bug 时建议先调成 `Debug`。应用内只显示当前文件筛选结果的尾部，完整文件走上面的目录。
- 别只看尾部几行就下结论：关键词过滤 + 往上下读堆栈。

## 崩溃

- 未捕获异常不会静默闪退，而是弹全屏崩溃页，含版本、设备、时间和完整堆栈。
- 让用户点「复制错误信息」，把完整报告（含堆栈与日志文件路径）发过来，不要让他自己翻日志。
- 崩溃日志同样落盘到上面的 `logs/` 目录，可直接读。

## 卡顿 / 发热 / 掉电

设置 → 数据与诊断 → 性能分析，看本应用 CPU、线程数、本应用内存（PSS，含容器子进程）、设备内存、流量。

- 数据每秒采样一次，**只在页面打开期间采样**，别指望关掉页面还有曲线。
- 「整机 CPU」显示「—」是正常的：Android 10 起普通应用读不到 `/proc/stat`。这是「读不到」，不是「空闲」，不要当成故障报给用户。
- 线程数在 AI 跑任务时上涨属正常。

## AI 请求失败

- 聊天页会先显示「正在重试 N/6」气泡，首行写失败原因；重试耗尽才显示红色错误气泡。
- 对着原因查：`连接被拒绝` 多半是供应商 Base URL 域名/端口写错；`DNS 解析失败` 是网络或域名拼写；`SSL 握手失败` 查协议与证书。
- 状态码：401＝Key 错误/过期，403＝权限或余额，404＝Base URL 路径错（如漏 `/v1`），429＝限流或额度，5xx＝服务端问题（与本地配置无关）。
- 开了多 Key 时，只有密钥本身有问题的错误（鉴权/权限/限流/余额）才换 Key；5xx、超时、断网换 Key 没用，也不会误切。
- 要改供应商配置走 `config` 工具，不要让用户自己翻菜单。

## 容器与环境体检

设置 → 容器与镜像 → 环境体检 → 开始体检，逐项给结论：共享存储访问权限、沙箱基础工具（`sh`/`git`/`curl`/`tar`/`xz`）、容器 DNS 解析（`github.com`）、容器出网（`api.github.com`）。

- 状态点：绿正常、黄需处理、红出错、**灰＝探测不到（沙箱忙或没启动），灰不是故障**。
- 基础工具缺失时下方有「安装」按钮一站式补装，装完自动重体检；它装在容器里、不进镜像，**重建镜像后要再装一次**。
- 首次使用必须先进终端页完成初始化（解压 rootfs + 基础工具）。AI 命令、Git、本地 MCP 全依赖它。

## 连不上远程服务器

- 对话页顶部显示 `SSH：已连接 / 连接中 / 连接失败 / 未连接`；未连接时消息区有等待提示。
- 断线后台自动重连（5 秒起、最长 30 秒退避），回前台立即重试一次。
- 报「SSH 主机密钥已变化」时**不要直接放行**：先让用户核对指纹，对不上就拒绝（防中间人）。
- 文件通道（SFTP）与命令通道（exec）是两条独立连接，一条异常不影响另一条。

## 长任务被系统杀掉

编译、深审这类长任务切后台就断，让用户开：设置 → 后台运行 →「后台运行保活」，设置 → 软件权限 →「忽略电池优化」+「自启动管理」。三个一起开才稳。注意 AI 执行期间本来就会自动保活，手动开的意义是「空闲时也常驻」。

## 别把「在等授权」当成卡死

多个会话（含子代理）可各挂一个授权请求。侧边栏里**橙色常亮**＝正在等授权（绿色脉冲＝执行中）。看到橙灯就让用户进那个会话放行，而不是重启 App。

## 纪律

- 先看日志再定性，不凭现象猜「官方挂了 / 没权限了」——历史上这类误判误伤过正常功能。
- 能读代码/文档核实的先核实；不确定就说不确定。
- 改 App 设置一律用 `config` 工具，不引导用户手动翻菜单。

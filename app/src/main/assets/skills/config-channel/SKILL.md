# 配置通道（config 工具）

读写 Aharou 自身设置的工具。**用户在界面上能改的项基本都在这**，所以「改设置」类诉求不要绕道让用户去翻菜单。

## 先查再改

- `action=list` 列出全部字段路径，集合会标注子项数。
- 路径是**点分**的：`appearance.theme`、`network.proxy_port`、`soul.name`。
- 集合子项在路径里带 id：`providers.1790610996623.api_key`。
- **不要凭记忆猜路径**，猜错了拿不到东西；拿不准就先 `list` 一次。

## 六个 action

| action | 用途 | 关键点 |
| --- | --- | --- |
| `list` | 列全部字段 | 集合只给名字与子项数，不给具体 id |
| `get` | 读一个字段 | 集合路径会返回该条的全部子字段 |
| `set` | 写一个字段 | `value` 是 **JSON 编码** |
| `add` | 集合下新增一项 | `path` 传集合名，`value` 传新项 |
| `remove` | 按 id 删集合里的一项 | 删前先用 `get` 确认 id |
| `logs` | 读应用日志（只读） | `date`=yyyy-MM-dd（缺省今天，只留最近 7 天）、`query`=关键词过滤、`limit`=行数（默认 200、上限 2000，从尾部取） |

### 排障先看 `logs`

Aharou 自己出问题（崩溃、闪退、某模块不工作、工具报错）时，**先用 `action=logs` 读日志**，并配 `query` 缩小范围（如 `query="ContextCompactor"`）。日志落在应用的外私目录，容器里根本看不见 —— 走这个动作读，读的是 App 自己管的那份文件，不需要 root / Shizuku。

读的是**尾部**：命中行多于 `limit` 时只回最后的，要更早的就调大 `limit` 或加 `query`。日志单文件超 5MB 会重置，所以别指望很久以前的行。

### `value` 的 JSON 编码

字符串要带引号，布尔和数字直接写：

- 字符串：`"zh"`、`"🦊"`
- 布尔：`true`
- 数字：`30`

写成 `zh`（不带引号）会被当成非法 JSON。

## 集合类字段（providers / remote.connections 等）

集合用的是 `add` / `remove`，不是 `set`：

- 先 `get <集合名>` 或 `list` 看清现有条目和它们的 id；
- 改**已有条目**的子字段用 `set <集合名>.<id>.<字段>`；
- 新增用 `add`，删除用 `remove` + `id`。

## 敏感字段读不到真值

标为敏感的字段（如 `network.proxy_password`、各家 `api_key`），`get` 返回的是占位文本 `••• (hidden)`，同时带 `sensitive: true`。

**这是设计如此，不要试图绕过。** 需要真值时直接问用户；要写入时照常 `set`（写进去是真的，只是读不出来）。

## 写操作会弹确认面板

`set` / `add` / `remove` 都会让用户确认后才生效，并写审计日志、支持一键改回旧值。

**所以不要拿它试探性乱写**：一次说清要改什么、改成什么，别连着改三版试效果。

## 生效时机

改完立即生效。个别字段需要重开会话或重连才看得出效果（如切换模型、改网络代理），这时告诉用户一声即可，不需要重启 App。

## 相关

- 某个 topic 的字段说明可以用 `topic-help` 查。
- 技能本身的启停也在这个通道里（`skill.skills.<技能名>.disabled`），但**新建/删除技能是文件操作**，得用文件工具建目录放 `SKILL.md`。

# 系统设置（com.android.settings）

## 界面结构

- 首页是分组列表，各厂商 ROM 的条目名与顺序差异很大，不要按固定文案找，先 dump 看当前页有什么。
- 大部分设置页顶部有搜索框，直接搜中文关键词比一层层点更快，例如「无障碍」「通知使用权」「电池优化」。
- 进入子页后返回用系统返回键，别点左上角，部分 ROM 的左上角是「跳到上级分组」而不是「回上一页」。

## 常见坑

- 不同 ROM 的包名不同：原生与部分国产 ROM 是 `com.android.settings`，厂商定制版可能另有一个设置应用。用 `a11y` 的 `foreground` 看当前前台包名最准。
- 权限页里「应用列表」很长，直接搜应用名，不要滚动到底。
- 「无障碍」页里开关被点开时会弹系统确认框（「允许此应用……？」），要点确认，否则每次都会退回关闭状态。
- 「通知使用权」「使用情况访问」「电池优化白名单」都在不同子页，名字因 ROM 而异，找不到就用搜索。

## 常用流程

- 开无障碍服务：设置 → 无障碍 → 已下载的服务 / 已安装的服务 → 找到 Aharou → 打开 → 确认框点「允许」。
- 开通知使用权：设置 → 通知与状态栏 → 通知使用权 → 找到 Aharou → 打开。
- 开电池白名单：设置 → 电池 → 电池优化 → 找到 Aharou → 选「不优化」。

## 边界

- 不要替用户修改「恢复出厂设置」「重置网络」「清除数据」这类不可逆项。
- 修改系统级开关（开发者选项、location、网络代理）前先说明会影响什么。

# 微信（com.tencent.mm）

## 界面结构

- 底部四个标签：微信 / 通讯录 / 发现 / 我。会话列表在第一屏。
- 顶部搜索同时返回联系人、群聊、聊天记录、小程序、公众号，结果是分组的，别把「公众号文章」当成「聊天记录」。
- 聊天页顶部标题才是当前会话对象。列表里显示的可能是备注名、群名或陌生人昵称，三者长得像，进会话后看标题最稳。

## 常见坑

- 会话列表和聊天页是自绘界面，部分机型上无障碍树读不到内容（`dump` 返回 `quality=unusable`）。这时不要反复按坐标盲点，先看截图，或用系统返回换一条路。
- 微信默认可能关闭辅助功能支持，必要时提示用户去「我 → 设置 → 通用 → 辅助功能」里开相关选项，开完再 dump 会明显变好。
- 弹出「选择要使用的应用」「微信分身选择」这类系统对话框时，前台包名会变成系统组件，不是微信，先处理掉弹窗再继续。
- 输入框里有文字只代表草稿，不代表已发送；发出后会话里出现气泡才算。
- 群聊消息每条都带发言人，转发/引用时别把发言人当成正文。

## 常用流程

- 发消息：会话列表点进目标会话 → 点底部输入框 → 输入 → 点发送按钮。
- 搜索联系人：顶部搜索框输入名字 → 结果里选「联系人」分组那一条，避免误点「聊天记录」。
- 发朋友圈：底部「发现」→ 朋友圈 → 右上角相机，长按相机是只发文字。

## 边界

- 涉及转账、红包、付款码的操作只做到「打开页面」，具体确认交给用户。
- 不要在用户没明确要求时群发消息。

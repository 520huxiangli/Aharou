# 哔哩哔哩（tv.danmaku.bili）

## 界面结构

- 底部标签：首页 / 动态 / 热门 / 会员购 / 我的（版本不同会调整）。
- 首页是推荐流，卡片里标题、UP 主、播放量挤在一起；`dump` 拿到的文本常常是长串拼接，按关键词定位比按位置更稳。
- 视频页是自绘播放器，控件层走 SurfaceView，无障碍树通常读不到进度条与播放按钮。

## 常见坑

- 播放页读不到控件时不要盲点屏幕中间试播放/暂停，那会触发点赞或弹出其他面板。用系统返回退出，或改用截图判断。
- 搜索结果里「视频」「番剧」「用户」「专栏」是分栏的，切栏后要重新 dump，旧节点 id 会失效。
- 登录、青少年模式、投屏这类操作会打断当前流程，确认用户意图后再做。
- 部分版本有开屏广告，点「跳过」的坐标每次不同，用 `find` 找「跳过」文本比记坐标可靠。

## 常用流程

- 搜视频：顶部搜索框输入关键词 → 回车 → 在「视频」栏里找目标条目。
- 看某个 UP 主：进视频页 → 点 UP 主头像或名字 → 进入个人主页 → 视频列表按发布时间排序。

## 边界

- 不要替用户充值、投币、开通大会员。
- 不要在未确认时点赞、收藏、关注。

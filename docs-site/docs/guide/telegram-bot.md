# Telegram 机器人

「设置 → 更多 → Telegram 机器人」把 Aharou 接到 Telegram：你在 Telegram 里给机器人发消息，本机跑一轮 AI 并把回复流式刷回聊天。人不在手机前也能远程指挥。

## 前置：申请一个机器人

1. 在 Telegram 里找 **@BotFather**，按它的指引新建一个机器人。
2. 它会给你一枚**机器人 Token**，复制备用。

## 配置

页面顶部是一张卡片，参数是**即时保存**的，没有「保存」按钮：

| 字段 | 说明 |
| --- | --- |
| 启用机器人 | 打开后，App 用前台服务在后台长轮询收消息 |
| 连接状态 | 未运行 / 正在连接… / 已连接：@机器人名 / 连接失败：原因 |
| 机器人 Token | 向 @BotFather 申请的那串 |
| API 基址 | 默认 `https://api.telegram.org`，一般不用改 |
| 代理（可选） | 填 `http://` 或 `socks5://` 开头的代理；**境内需要配代理才能连上** |

开关变更会拉起或停掉后台上报服务。

::: tip 通知权限
Android 13 及以上，打开开关时若还没授予「通知」权限会顺带申请一次。通知权限只影响后台服务通知是否可见，不影响收发消息。授权方式见[后台运行](/guide/background-run)。
:::

## 配对：谁能和机器人说话

陌生聊天第一次发消息不会直接进 AI，而是收到一枚 **6 位配对码**（10 分钟内有效）：

1. 对方在 Telegram 里把配对码发给你。
2. 你在「**待配对**」列表里点 **通过** 或 **拒绝**。
3. 通过后，该聊天进入「**已配对**」；之后的消息才交给 AI 处理。

- 群里未配对者**不会**收到配对码（避免把群刷爆）；只有私聊才会发码。
- 群里只有 **@机器人** 或被回复该机器人的消息才会应答，私聊一律应答。
- 想断开某人：在「已配对」里点它右侧的「移除」，下次来消息会重新发码。

## 工具审批

机器人在跑工具时若需要你确认，会在 Telegram 里发一条带按钮的消息，只有 **允许** 和 **拒绝** 两个选项：

- **允许**：放行**这一次**，等同弹窗里点「允许」。
- **拒绝**：拒绝这一次。

按钮**不会**给「始终允许」——永久授权只在 App 里下放。点完按钮后消息会更新为「已允许 / 已拒绝」。

## 回复怎么显示

AI 的回复会**流式**刷回 Telegram：先发一条消息占位，之后按片刻原地刷新；工具执行期间占位显示「正在使用 xx…」。出错时，已经流出的部分留在原地，另外补发一条错误说明。

## 出错怎么办

- **连不上 / 一直「正在连接…」**：先确认 Token 正确；境内需在「代理」里填一个可用代理。
- **发消息没反应**：检查对方是否已配对（在「待配对」里通过）；群里记得 @ 机器人。

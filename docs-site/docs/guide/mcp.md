# MCP 服务器

MCP（Model Context Protocol）让 AI 接入外部工具——查数据库、搜网页、控制浏览器之类。连上之后 AI 就能调用这些工具，用法和内置工具一样。

一个服务器动辄几十个工具，把它们的完整定义全部塞进每一轮请求会吃掉大量上下文（服务器一多，光这部分就可能占几十万字符）。**v2.1.0 起**改成按需加载：平时只把「服务器名 + 工具名 + 一句话描述」列给 AI，AI 需要时自己搜一下，命中的工具才展开成完整定义。对你来说没有额外操作——AI 自己会去搜。

入口在「设置 → AI 配置 → MCP」。

## 两级作用域

MCP 配置分全局和项目两级：

- **全局**：所有项目共享，配置存在 `~/.aharou/mcp.json`。
- **项目级**：只在当前工作区生效，配置存在 `<工作区>/.aharou/mcp.json`，可以随项目一起提交到 git。

实际生效的是两者合并的结果，**项目级优先**——同名的服务器，项目里的配置会覆盖全局的。

## 服务器列表

每行显示服务器名称、来源（全局 / 项目）、类型（stdio / HTTP）、连接状态，已连接时还会显示工具数量，本地 stdio 服务未连接时显示启动命令。

- 点行进入编辑。
- 左滑露出删除按钮，删除作用于该行标注的作用域。
- 右上角「重新连接」一键重连所有服务器，「+」添加新服务器。

如果你在容器内或用外部编辑器直接改了 `mcp.json`，App 会在几秒内自动发现并刷新：新增或启用的自动连接，删除或禁用的自动断开，不需要重启。

## 添加服务器

编辑页顶部先选**作用域**（新增时默认「项目」，编辑已有条目保持原作用域），下面的「是否启用」控制它是否参与连接。剩下的字段按传输类型分两种。

**名称**只作别名，但它会拼进给模型的工具名（`mcp__名称__工具名`），因此只能含字母、数字、下划线、连字符；填了中文之类的字符会提示错误且无法保存。

### 远程 HTTP

- **名称**：别名，比如 `fetch`、`github`。
- **服务器地址**：远程服务端的 Streamable HTTP 链接。
- **自定义请求头**：键值对，用来填认证 Token 这类固定头部。

### 本地 stdio

- **名称**：别名。
- **启动命令**：`npx`、`node`、`python` 之类。
- **命令参数**：逐项添加，比如 `-y`、`@modelcontextprotocol/server-xxx`。
- **环境变量**：传给这个进程的键值对，比如 API_KEY。

stdio 服务器需要在容器里跑：本地模式跑在当前容器上，远程 SSH 模式下跑在「默认容器」上。切换容器后所有 stdio 服务器会自动断开并用新容器重连，HTTP 服务器不受影响。

## 工具管理

连接成功后，编辑页的「工具」标签页会列出这个服务器提供的所有工具，每个工具一张卡片，显示描述和参数名。

- 右上角的开关可以**单独禁用某个工具**，禁用后它不再提供给模型，能省一些上下文。
- MCP 工具和内置工具走同一套权限机制：默认每次调用都要你确认，可以在授权弹窗里选「始终允许」记住。
- 没检测到工具时点右上角刷新重新拉取。

编辑页右上角的日志按钮可以跳到「日志」页并自动按这个服务器名过滤，排查连不上的问题时很有用。

## 连接器目录

不想手敲服务器地址，可以从内置的**连接器目录**里挑。入口在「设置 → AI 配置 → MCP」页面顶部那一行「浏览连接器」。

1. 点「浏览连接器」进入目录页。
2. 顶部搜索框按关键词过滤；下面一排分类胶囊（**全部** / 文档检索 / 开发工具 / 效率协作 / 云与数据 / 支付财务），点一下只看这一类，再点同一类取消。
3. 每条列出名称、鉴权标签和一句说明；右侧的 ↗ 是「查看文档」，会跳到该服务的官方接入文档。没有匹配结果时显示「没有匹配的连接器」。
4. 点中意的一条，会直接打开**新增表单**，并预填好**名称**和**服务器地址**；剩下的鉴权（令牌、自定义请求头）按提示自己补，然后照常保存。

鉴权标签的含义：

| 标签 | 含义 |
| --- | --- |
| 无需授权 | 直接可用 |
| 可选授权 | 匿名也能用（一般有限速），填令牌可提升额度 |
| 需填令牌 | 必须提供 API Key / PAT 之类的静态令牌 |
| 需 OAuth | 官方只支持 OAuth 授权流程 |

目录内容是内置的、不联网，只收录**远程 HTTP** 类型的常用服务器；本地 stdio 服务器仍需按上文自己添加。

## 让 AI 帮你配

复杂的 MCP 配置可以直接让 AI 做，它有专门的管理工具，可以指定装到全局还是项目。新增或移除后配置**在下一次会话生效**（新建会话时会自动连接未连接的服务器）。

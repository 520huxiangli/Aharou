# 定时任务

::: tip 版本说明
定时任务从 v2.8.2 起提供。
:::

定时任务让 AI **按固定周期自动跑一条指令**，不用你每次开口。适合「每天整理一次工作区」「每小时巡检一遍某件事」这类周期性动作。

## 怎么用

进入「设置 → AI 配置 → 定时任务」，点右上角「＋」新建：

| 字段 | 说明 |
| --- | --- |
| 名称 | 任务名，会出现在任务列表、会话标题和通知里 |
| 周期 | 多少分钟跑一次；**最短 15 分钟**，填更小的值会被收敛到 15 |
| 运行位置 | **每次新建会话**：每次到点都开一个新会话（需要填工程工作区）；**指定会话**：固定在某一个已有会话里跑 |
| 指令 | 到点发给 AI 的内容，等同于你在那个会话里打的一段话 |
| 运行上限 | 累计跑多少次后停止；填 `0` 表示不限 |
| 启用 | 关掉后不再触发，但配置保留 |

保存后任务立刻进入调度。列表里每一行会显示周期、下次运行时间（带「约几分钟后」的倒计时）、已运行次数与上限；开关可以随时启停，左滑删除。

## 到点会发生什么

- 应用**每 15 分钟**检查一次有没有到点的任务（这是系统调度周期，也是周期下限的来源）。
- 到点后在目标会话里**跑一轮普通对话**——和你说一句话完全一样的链路，含工具调用、授权弹窗与上下文压缩。
- 同一个任务在同一时刻**只会被触发一次**：认领是带条件的更新，多个检查撞上时只有一个能拿到。
- **不补跑**：如果应用长时间没打开，某次运行迟到超过一个周期，这一次会被跳过并标注「上次错过未补跑」，只把时间推到下一个周期。这样避免开机后连着补跑好几轮、既费额度又把会话刷满。
- 没有任何启用中的任务时，不会安排周期检查，也就不会为它唤醒进程。

## 出问题怎么看

- **没跑**：先看任务是否启用、是否已达运行上限；再看目标会话里有没有那一轮记录。
- **标了「错过未补跑」**：说明到点时应用没在运行，属预期行为，下一次会照常。
- **跑得很慢或没结论**：和普通对话一样，去目标会话里看这一轮的工具调用与输出。

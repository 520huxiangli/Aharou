# 外观与语言

「设置」首页进「通用设置」后，点「外观主题」或「语言」会弹出底部选择窗口，选完立即生效并保存。背景图也在「外观主题」面板里。

## 外观主题

面板里分几块：明暗模式、配色方案、自定义颜色、聊天外观、动态取色。选完不会自动关窗，方便连着试几套配色对比。

### 明暗模式

三选一：自动、深色、浅色（自动即跟随系统）。

有些皮肤本身就偏深色（夜墨、玄青），选「自动」时它们直接就是深色；想强制用它们的浅色版本，把明暗模式切到「浅色」即可。反过来，浅色皮肤也各自有一版深色配色，切到「深色」时用那一版。

### 配色方案

六套皮肤，深浅两种模式各自配好：

- **青蓝**：冷静的工具感，默认皮肤。
- **夜墨**：深色常驻，适合夜间与长时间盯屏。
- **松绿**：健康 / 财务 / 效率，圆角略大。
- **空紫**：创意 / AI / 社区，大圆角更柔和。
- **霞橙**：暖调高亲和，电商 / 社交 / 活动页。
- **玄青**：OLED 纯黑高对比，极客向。

色块里外圈是该皮肤的页面底色、内圈是主色，预览会跟着当前明暗模式变。

**圆角随皮肤走**：整体一起平移（霞橙最大、青蓝最小），不会出现某一块圆某一块方。切换皮肤时整页底色、卡片面、分隔线、导航栏一起变。

从旧版本升级过来的话，之前选的咖啡 / 石墨 / 森林会自动接到最接近的新皮肤，不会突然变回默认。

### 自定义颜色

想自己调一套，点「自定义颜色」进入编辑器：

- **主色**：拖「色相 / 饱和度 / 明度」三个滑块，下面的预览实时更新——看到的就是保存后的样子。
- **辅色**（可选）：影响渐变与少量点缀，不设也行。
- **名字**：给它起个名字，保存后会出现在配色方案那一排，和六套预设并列。
- **分享 / 导入**：「复制 JSON」把皮肤内容复制到剪贴板，发给别人；对方「导入 JSON」粘贴进来即可载入，「载入」后还要点一次保存才会加进列表。
- **删除**：点一下已经选中的自定义皮肤（再点一次会打开编辑器），编辑器左下角有「删除」。删掉正在用的那套会回到默认皮肤。

两条保证：**语义色不跟着改**——不管你把主色调成什么，绿仍然是成功、琥珀仍然是警示、红仍然是危险。**文字对比度自动兜底**，选到很浅或很深的颜色也不会出现看不清的字。

### 聊天外观

我的气泡和助手气泡分开设置：

- **我的气泡**：默认跟随皮肤；关掉「跟随皮肤」后可以自己选颜色与不透明度。
- **助手气泡**：默认关闭。Aharou 的对话区是扁平的文档流——助手正文直接铺在页面上，没有气泡。打开这个开关后助手消息也会套上气泡，和你的消息对称。
- **圆角**：两种气泡共用一个圆角，拖动即时预览。

气泡里的文字颜色会按底色自动取对比色，不用担心换成浅色底后文字糊掉。

### 动态取色（莫奈取色）

开启后从系统壁纸提取配色，上面选的配色方案不再生效（那几块色块会变淡并置灰，点不动）。默认关闭。

需要 Android 12 及以上系统；低版本设备上开关不可用，描述会直接提示。壁纸调色板由系统生成，不同手机厂商的取色结果差异较大，觉得不好看关掉就行。

## 自定义背景图

在「外观主题」面板的下方可以设一张全局背景图：

- **选择图片**：从系统相册选一张作为 App 全局背景，叠在所有页面内容上（水印效果，不拦截触摸）。终端页保持纯黑底，不显示背景。
- **透明度**：滑块显示 0% 到 100%，实际生效范围映射到 0% 到 20%（也就是滑到 100% 相当于 20% 不透明度），这样保证文字始终可读。默认 15%，拖动实时生效。
- **移除背景**：恢复默认纯色背景。

背景图文件保存在应用私有目录，**不随备份导出**，换设备需要重新设置。

## 语言

可以跟随系统语言，也可以直接指定一种已支持的语言。

## 终端外观

终端的配色主题、字体、字号、光标样式是单独一套设置，见[终端](/guide/terminal#外观设置)。

代码编辑器的语法高亮、Git 泳道色、日志级别色与 diff 增删红绿也都各自独立，不随皮肤改——它们是功能标识，含义要在任何皮肤下都一致。

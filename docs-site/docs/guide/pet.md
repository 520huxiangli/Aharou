# 小染

「设置 → Aharou 助手 → 小染」可以把小染放到屏幕上当贴身伙伴。她盖在其它 App 之上，一个人包了四件事：陪着你、显示 Agent 进度、显示通话字幕、替你报天气和节日——所以原先那枚「状态胶囊」已经并进她身上，不再单独存在。

## 需要的权限

设置页最上面就是这份清单，哪一项没开都写着「未授权」，点那一行就能去开：

| 权限 | 为什么需要 |
| --- | --- |
| 悬浮窗权限 | **必须**。没有它，屏幕上根本看不到她 |
| 录音权限 | 语音通话要用。没有它她听不见你，也说不了话——在菜单里点麦克风时她会直接告诉你 |
| 通知权限 | 保证她不被系统顺手清掉；你把她隐藏或切成摆件模式后，也是靠这条通知把她叫回来 |
| 定位权限 | 只有「天气与节日提醒」要用。开了它才会读一次位置，坐标只发给出天气的接口 |
| 无障碍服务 | 只有菜单里的「截屏」要用。没开也能用她其它功能，点截屏时她会提醒你去开 |

打开「显示小染」之后，通知栏还会有一条常驻通知，这是 Android 对前台服务的硬性要求。

## 两个开关的分工

| 开关 | 作用 |
| --- | --- |
| 显示小染 | 总开关。关掉等于停掉悬浮服务，通知也一起消失 |
| 常驻待机 | 打开：她一直站在屏幕上；关闭：只在 Agent 跑任务或通话时出现（等同原来那枚胶囊的行为） |

## 她什么时候出现

满足**任意一条**就出现：

- 常驻待机开着；
- Agent 正在跑任务，而且 Aharou 不在前台；
- 正在语音通话。

如果你从菜单里把她**隐藏**了，那就只剩通话能把她叫回来——否则通话会没有可用的界面。

## 操作

| 操作 | 效果 |
| --- | --- |
| 按住拖动 | 挪位置（位置会记住；锁定位后拖不动） |
| 快速滑动后松手 | 她会**被甩出去**，带惯性滑一段，撞到屏幕边会软软弹回来 |
| 单击 | 说一句话（随手挥个手） |
| 双击头部 | 摸头，她会缩一下脖子，好感度 +2 |
| 长按头部 | 唤出环形菜单 |
| 长按身体（不是头） | 抱一下 |
| 连着戳三次 | 她会烦，脑袋一甩吐槽一句，好感度 −3 并别扭几分钟 |
| 点那个小球 | 球会再弹一下 |

## 环形菜单

长按头部唤出一圈按钮，**从正上方开始顺时针**依次是：

| 顺序 | 按钮 | 作用 |
| --- | --- | --- |
| 1 | 通话 | 开关语音通话；通话中这一项高亮 |
| 2 | 截屏 | 截当前屏幕，直接发进聊天会话（详见下节） |
| 3 | 彩蛋 | 随机弹一张梗图到屏幕上，点图关掉（详见〈彩蛋〉） |
| 4 | 说话 | 冒一句台词 |
| 5 | 扔个球 | 扔一个小球出去，落地后她自己跑过去捡 |
| 6 | 隐藏 | 让她从桌面消失，通知变成「点此叫回」的入口 |
| 7 | 摆件模式 | 整块窗不接触摸，手指直接穿过去（详见下节） |
| 8 | 打盹 / 叫醒 | 睡一会儿；已经睡着时这一项变成「叫醒」 |

点菜单外面的空白处即可收起。

## 贴边收起（她会缩到屏幕边上探头）

没人理她的时候，她会溜达到屏幕**最左或最右**贴着边站住，停一会儿就**缩进屏幕边里**——换成一张专门的「探头」姿势：侧着身子、只露头和肩膀，一只手扶着屏幕边缘。

- **碰一下就出来**：点那一条她会滑出来（单击＝说话、长按＝出菜单、按住拖＝直接拎走）；
- **不会赖着不出来**：你把她叫出来后 20 秒内她不会再缩回去；
- **有事会自己出来**：菜单打开、有任务进度字幕、你扔球她会去追，这三种情况她都会先出来；
- 缩着的时候窗口只有她露出来那一块那么大，不会整条屏幕边都挡住点不到。

> 小染（PNG 角色）用的是专门画的「探头」素材，不是把站立图裁一刀；虎鲸娘（视频角色）没有对应的半身素材，改用**把窗口整体滑出屏幕一截**（留 40% 在外面）的做法，效果一样，素材作者的桌面版也是这么干的。

## 截屏

菜单里点「截屏」，她会**截当前屏幕并直接发进聊天会话**（发完她会响一声、冒一句话告诉你）。

- 截图前她会先**把自己和那颗球收起来**，所以截出来的画面里没有她，AI 不会去解读桌宠本身；
- 截图落成工作区里的附件文件（`<工作区>/.aharou/attachments/shot_<时间>.jpg`），你可以点开看；
- 发去的是**最近聊过的那个会话**（跟说话、语音通话同一个），聊天界面没开着也照发，消息和 AI 的回复都会留在会话里。

**前提**：得开着**无障碍服务**（截屏能力来自它）。没开的话点截屏她会告诉你，并把 App 叫到前台让你去开：设置 → 权限与后台 → 无障碍。Android 11 以下不支持系统截屏。


## 她自己在干什么

没人管她的时候，她有自己的小日子：

- **待机**：面对你轻轻呼吸；
- **四处张望**：隔一会儿往左或往右边看两眼，再转回来；
- **溜达**：自己走到别处，走路时换成侧视图并两帧交替迈步（腿分开／并拢），带上下起伏和轻微前倾。**多数时候她会往屏幕左右两侧走**——贴边站着挡到的东西最少；
- **打盹**：没人搭理她超过一分半，她就换个姿势睡下，头顶冒「Zzz…」，呼吸变慢变深。深夜（23 点到早上 6 点）阈值缩到 20 秒，她会更早睡。碰她一下或来电话就把她叫醒。

## 她对你的态度

她记着你怎么对她。好感度会落盘，跨重启保留，设置页能看到当前档位：

- **摸头、陪着她** → 加分；
- **一直戳她** → 掉分，并别扭几分钟；
- **隔好几天不出现** → 缓慢变淡，但有下限，关掉 App 一周回来不会变成陌生狐。

档位分**冷淡 / 平常 / 亲近 / 黏人**四档，直接决定她说哪种话：冷淡时问什么都是「……哼」，黏人时摸头会说「再摸一下也行」。隔了三天以上没见，她现身时还会说一句重逢的话。

## 她会说话（带记忆）

在菜单里点「说话」或直接单击她，她会**带着记忆**去现说一句：AI 会参考记忆库里那些关于你的事（比如你提过要早睡），说出一句贴合当下的短话，而不是从固定台词里挑一句。

- 说的时候头顶气泡显示那句话，她会顺手挥个手；
- 连续戳她时不会每次都去生成（有冷却），这段时间她改用平时那套台词；
- **没配 AI 供应商、没网、或生成失败时，她会退回固定台词**——她可以哑，但不会张嘴却没话。

## 每天早上的一句

打开「天气与节日提醒」后，她每天第一次出现在屏幕上时会报一句：

- **节日祝福**（元旦、春节、元宵、清明、劳动节、端午、七夕、中秋、国庆、重阳、圣诞、跨年）；
- **今日天气与注意事项**：气温区间，加上最要紧的一条提醒（可能下雨带把伞／挺热多喝水／降温加衣／有雪路滑／雷雨别乱跑／紫外线强），天气数据来自 Open-Meteo。

一天只说一次，记在当天。没给定位权限也不会报错——她只是不报天气，节日照说。

> 农历节日的公历日期是逐年变化的，内置表只写了有可靠来源的年份；表外年份她只报公历节日，不会瞎猜。

## 你跑任务的时候

- Agent 跑完一个**超过 20 秒**的任务，她会冒一句「干完了，你去看看？」；
- 任务**卡在等你确认**（工具授权弹窗或计划审查）超过 20 秒，她会响一声提示音并冒一句提醒你——只提醒一次，你点掉确认后重新计时。

## 扔球陪玩

菜单里点「扔个球」，小球会从她手边抛出去，落地弹两下停住；她**自己跑过去捡**，捡到会说一句。球停着的时候你点它，它会再弹一下，她又会跑一趟。

## 摆件模式

打开后她的整块窗不接触摸，手指直接穿过去——她还在屏幕上，但完全不挡你操作。适合开会、录屏、给别人看手机的时候。

**注意**：开着之后长按菜单也叫不出来（因为点不到她）。关掉只有两条路：**设置 → Aharou 助手 → 小染 → 摆件模式**，或者下拉通知点「取消摆件」。

## 气泡

她头顶的气泡按优先级显示：

1. **通话字幕**——通话中一直显示，谁在说就显示谁的话；
2. **Agent 进度**——当前工具名与状态；
3. **台词 / 每日一句 / 任务播报**——几秒后自动收回。

气泡只在有内容时出现，平时头顶不会留一块空白。

角色自带画好的「图片气泡」时，随机搭话有几率直接冒图（图里就是那句话），和文字气泡共用同一块位置，显示几秒后收回。

## 通话

通话的显示完全落在她身上：**通话中她一定出现**（哪怕你把她隐藏了），字幕实时走她头顶的气泡；挂断或接通都在长按菜单的「通话」里。没给录音权限时点麦克风不会起通话，她会说明原因并把你带回 App 去授权。

::: warning 需要开启悬浮
通话依赖她显示字幕。如果「显示小染」是关的，通话仍然可以进行，只是看不到字幕。详见[语音通话与朗读](/guide/voice)。
:::

## 彩蛋

长按小染头部唤出菜单，点「彩蛋」，屏幕上会随机跳出一张梗图（哈基米、鱼片、无钱之类），落在随机位置，**点图即关**；可以连点几次弹出一叠，一一点掉。

素材是随角色带的（`assets/pet/<角色>/easter/`），小染和虎鲸娘各有一套（暂未单独区分）。

## 换角色

「桌宠角色」点一下弹出角色列表，选中即换，立刻生效（不用重启 App、不用重开开关）：

- **小染**：默认角色，PNG 立绘一套（正面／侧面／走路／打盹／探头），带 4 张画好的图片气泡；
- **虎鲸娘**：视频角色，素材是 91 段动作短片（待机呼吸、原地漂浮踏步、螃蟹走路、东张西望、5 种点击回应、拖拽反馈，另加 80 个随机小动作：吃饺子、写代码、撸猫、放孔明灯……）。

两套素材的播放方式不一样：小染是静态立绘拼动作，虎鲸娘是真的在放视频。视频自带透明通道的编码不支持，所以素材是「左右拼合」的——画面左半边是彩色、右半边是一张灰度遮罩，App 在渲染时把两半合起来，看起来仍是透明立绘而不是一个视频方块。

视频角色的动作是**跟状态走**的：待机放呼吸、走动放踏步、看旁边放东张西望、睡觉放小憩沉眠、你点一下换一种点击回应、闲下来随机放一个小动作（每个只放 4 秒就回常驻）。拖到屏幕边上缩起来时，它是把窗口滑出屏幕一截（留 40% 在外面），而不是换成探头姿势。

已知差别：**虎鲸娘没有 PNG 角色那种「只露半个头」的探头姿势**（素材里没有），所以它贴边时是整个人滑出去一半。

不同角色的素材齐不齐差很多：没画到的动作会自动用正面图顶上——看着不像在走路，但不会缺图、不会消失。

## 尺寸与位置

「小染大小」点一下在小 / 中 / 大之间循环（默认中）。位置会自动记住，屏幕旋转后会自己回到可见范围；不想被误碰就打开「锁定位置」——锁定只挡拖动，长按菜单和单击说话仍然可用。

## 注意事项

- **她只会挡一点点**：悬浮窗是一块矩形，Android 不允许逐像素穿透，所以角色身体覆盖的那一小块会挡住下面的点击；实在嫌挡就开**摆件模式**。另外**长按菜单展开时那块矩形会临时变大**（为了装得下圆环），菜单一收起立刻恢复。
- **耗电**：动画平时约 30fps，菜单展开时降到约 5fps、打盹时约 9fps；扔出去的小球在场时保持 30fps。长期不用建议关掉总开关。
- **自动恢复**：开关开着时，设备重启或 App 更新后她会自己回来。

## 出错怎么办

- **开了开关却看不见她**：先看「需要的权限」里悬浮窗那一行是不是「未授权」；也可能是被国产 ROM 的后台限制拦了，去「设置 → 权限与后台 → 软件权限」按提示放行。
- **点麦克风没反应**：多半是录音权限没给，她会明说一句并把你带回设置页。
- **点不到她了**：检查「摆件模式」是不是开着——开着就是点不到，去设置里关或点通知里的「取消摆件」。
- **她老是说同样的话**：说明这次没走成「带记忆生成」——检查 AI 供应商是否配置好、网络是否正常；连着戳她也会走固定台词（有冷却）。
- **不报天气**：看「定位权限」是否已授权，以及「天气与节日提醒」开关；当天已经报过一次就不再重复。
- **拖不动她**：检查「锁定位置」。
- **找不到她了**：如果是从菜单隐藏的，点通知里的「已隐藏，点这里叫回小染」；如果是总开关关了，回设置里打开。
- **她跑到屏幕外了**：关掉总开关再打开，或旋转一次屏幕，她会自动贴回可见范围。

# 桌宠

「设置 → 桌宠」可以把小染放到屏幕上当一枚桌面伙伴：她会待机呼吸、自己溜达、转身偷懒，点一下还会说话。她盖在其它 App 之上，不占聊天界面。

## 开启

1. 先授权 **悬浮窗权限**——在「设置 → 桌宠」里点「悬浮窗权限」那一行，跳到系统设置打开「显示在其他应用上层」。部分国产 ROM 还需要允许「后台弹出界面」并保持自启动（见[软件权限](/guide/app-permissions)）。
2. 打开「启用小染桌宠」。她会出现在屏幕右下角；关掉开关她就消失。

开启期间通知栏有一条常驻通知，这是 Android 对前台服务的硬性要求，用来保证她不被系统随手清掉。

## 她会做什么

- **待机**：面对你站着，轻轻呼吸。
- **走动**：隔几秒自己走到屏幕另一头，走的时候换成侧面，向左走自动镜像。
- **转身**：偶尔背过身去（背面）。
- **说话**：点一下她，头顶冒出一句台词，几秒后自动收起。

## 操作

| 操作 | 效果 |
| --- | --- |
| 按住拖动 | 把她挪到任意位置（位置会自动记住） |
| 单击 | 说一句话 |
| 双击 | 换朝向：正面 → 侧面 → 背面 |

## 设置项

- **桌宠大小**：点一下在小 / 中 / 大之间循环。
- **锁定位置**：锁上之后拖不动她，避免误碰（位置记忆仍然生效）。

## 注意事项

- **她只会挡一点点**：悬浮窗是一块矩形，Android 不允许逐像素穿透，所以角色身体覆盖的那一小块会挡住下面的点击。窗口已经收紧到角色轮廓附近，但手指正好落在她身上时点不到下面的 App，属正常现象——想透过去就先拖开她，或者直接关掉桌宠。
- **耗电**：她是约 30fps 的轻量动画，静止时开销很小；长期不用建议关掉开关。
- **与状态胶囊互不影响**：桌宠和「Agent 干活时的状态胶囊」是两个独立开关，可以同时开——桌宠默认在右下角、胶囊在左侧。
- **自动恢复**：开关开着时，设备重启或 App 更新后她会自己回来，不用重新打开。

## 出错怎么办

- **开了开关却看不见她**：多半是悬浮窗权限没给。回到「设置 → 桌宠」看「悬浮窗权限」是不是「未授权」，点那一行去开。也可能是被国产 ROM 的后台限制拦了，去「设置 → 软件权限」按提示放行。
- **拖不动她**：检查「锁定位置」是不是开着。
- **她跑到屏幕外了**：关掉开关再打开（或旋转一次屏幕）她会自动被拉回可见范围；想固定住就开着「锁定位置」。

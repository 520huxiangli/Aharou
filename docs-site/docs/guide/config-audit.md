# 配置审计

「设置 → Aharou 助手 → 配置审计」记录 AI 通过 `config` 工具对 Aharou 自身设置的每一次修改尝试，并支持一键改回旧值。

列表里每条包含状态、发起方、时间、字段名，以及「旧值 → 新值」。页面顶部显示已记录条数——底库最多保留 **1000 条**，页面展示最近 **200 条**。

## 状态

| 状态 | 含义 |
| --- | --- |
| 已生效 | 你点了「同意」，改动已写入 |
| 被拒绝 | 你点了「驳回」，没有改动 |
| 超时 | 确认框 120 秒没回应，按未同意处理 |
| 已撤销 | 事后被改回了旧值 |

发起方显示「AI」（AI 主动发起）或「手动撤销」（你在审计页撤销的）。

## 撤销

「已生效」的记录右侧有「撤销」，点击会确认「会把这个字段改回旧值，并记一条撤销记录」。确认后：

- 字段改回旧值；
- 原记录标成「事后已撤销」；
- 同时**新增**一条撤销记录——历史只增不删。

撤销只对「已生效」且支持写回的字段有效，字段不存在、不可写或旧值解析不出来的，会直接给失败提示。

## 敏感字段

API Key、Token 这类敏感路径，列表里的值默认打码显示。

只有当这一页**确实存在敏感记录**时，页头右侧才会出现眼睛图标；点一下切换成明文，再点收起。默认是关着的，不会一进页面就把密钥摊在屏幕上。撤销确认弹窗跟随这个开关——开着显示明文，关着仍是打码。

显不显示只影响屏幕上的呈现，撤销读的始终是真实值，切不切开关都不影响撤销结果。

## 两点边界

- 审计**只覆盖配置通道**，也就是 AI 通过 `config` 工具发起的修改。你自己在设置页里的手动改动不会进这里。
- AI 每次发起配置修改都会弹确认框，不同意就不会写。框里按「旧值 → 新值」展示：前面那个旧值打码遮住，后面即将写入的新值是明文——这样你能看清 AI 到底要改什么，不必对着两串掩码盲签。同一时刻只会有一个确认框；App 在后台时会发通知提醒，超时就按「超时」记录。

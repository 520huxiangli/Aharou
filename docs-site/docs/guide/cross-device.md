# 跨设备协作

「设置 → 更多 → 跨设备协作」把本机做成一个**同一局域网内可被调用的执行端**：另一台装了 Aharou 的设备配对后，可以请求本机读文件、写文件、执行命令、截图。默认关闭。

## 开启与配置

| 项 | 说明 |
| --- | --- |
| 开启跨设备协作 | 启动本机服务；关闭开关时会停掉服务并清空全部授权与配对码 |
| 设备名 | 对端看到的名称；留空用机型名 |
| 端口 | 服务监听的端口（1024–65535） |
| 远端动作每次都需确认 | 默认**开启**：远端来源的动作即便本机策略本可自动放行，也升级为一次审批 |

## 配对

服务开启后，页面会显示：

- **生成配对码**：点开生成一枚 **6 位码**，**5 分钟内有效、一次性**；过期后可点「重新生成」。
- **本机端点**：对端用来连接本机的地址。

在另一台设备的 Aharou 里，填「URL + Bearer token」接入；用配对码换到长期令牌后即可调用。

## 授权与撤销

- 读文件、写文件、执行命令、截图这些远端动作到本机时都会**弹一次审批**（默认设置下；只返回设备名/版本的查询不弹），弹窗与通知栏是同一套。点「允许」才执行；拒绝或超时都不执行。
- 远端来源的调用**不会**写成「始终允许」规则，避免把远端需求变成本机自身的长期放行。
- 「**已授权设备**」列出每台设备的授权时间与最近活跃；在列表里**左滑**露出撤销，确认后即可**撤销授权**。撤销后该设备需重新配对才能连接。

## 安全提示

::: warning
一旦开启，局域网内任何拿到配对令牌的设备都能请求本机执行动作。所以默认全关、默认每次审批。不用时请关掉开关——关闭会一并清空所有授权与配对码。
:::

## 出错怎么办

- **对端连不上**：确认两台设备在同一局域网、本机开关已打开、端口没被占用、端点地址填对。
- **动作被拒**：到本机看审批弹窗或通知栏，点「允许」；若一直没人应答，会按超时（约 90 秒）拒绝。

# 存储空间

「设置 → 存储空间」按类别展示 Aharou 在这台设备上占了多少空间，并提供清理临时数据的入口。

## 总览

页面顶部是应用总占用、构成条与设备剩余空间。构成条的整条宽度代表应用总占用，颜色与下方各分类的色点一一对应。

统计需要逐个目录遍历文件，容器与工作区通常最慢。为了不让页面一直空着，各分类算完一个就显示一个，尚未算出的显示「—」，顶部会有「统计中…」提示。想重新统计点右上角的刷新图标。

## 占用明细

| 分类 | 包含什么 |
| --- | --- |
| 聊天记录 | 数据库文件：会话、消息、工具结果、调用记录、检查点索引 |
| 容器 | 各容器的根文件系统。展开可看到每个容器，以及占用最大的那个容器里最大的几个目录 |
| 容器镜像包 | 下载或导入的镜像压缩包。容器装好后它不再是必需品，但删掉后该容器无法再次解压 |
| 工作区 | 应用内置工作区里的项目文件（含 `.git`）。展开可看每个项目，副标题标出其中的聊天附件 |
| AI 配置与产物 | 技能、记忆、子代理、MCP 配置、提示词、文档，以及工具输出存档与识图会话缓存 |
| 离线语音模型 | 下载的离线语音模型（`filesDir/voice_models`），按模型逐项列出 |
| 检查点 | AI 修改文件前留下的快照，用于撤销 |
| 日志 | 应用运行日志与 AI 请求日志 |
| 缓存 | 系统缓存目录，随时可清 |
| 其他数据 | 设置项、背景图、终端字体、SSH 私钥等零散数据 |
| 应用安装包 | APK 本体，不可清理 |

带箭头的分类点一下可以展开明细。

::: tip 哪些不计入
通过「添加本地目录」加进来的外部工作区在你设备的共享存储里，不属于应用占用，因此不统计。远程 SSH 模式下服务器上的文件同理。
:::

聊天记录的展开明细列出占用最大的几个会话。它是按消息正文估算的字节数，比数据库文件本身小——数据库还包含索引与页对齐开销。想减小这一项，去会话列表删掉不再需要的会话；只想清调用记录的话，在「Token 统计」页右上角重置。

容器和工作区不能在这里删除，请到「容器与镜像」页重置或删除容器、在工作区切换面板里删除工作区，避免误删正在用的环境。删除工作区会连同该工作区的聊天记录一并删除；外部本地工作区是否删除聊天记录，由「偏好设置」中的开关决定。

## 可释放空间

这一组里的四项都是可以安全删掉的临时数据，删除后功能不受影响：

- **缓存文件**：临时文件，之后会自动重建。
- **运行日志**：应用日志与 AI 请求日志。清空后新日志照常记录。
- **工具输出存档**：AI 工具输出过长时会落盘一份完整副本。清掉后，历史消息里提到的输出路径不再能读取。
- **识图会话缓存**：识图追问用的历史记录。清掉后无法再对旧图片继续追问。

每项右侧的「清理」会先弹确认框，显示将删除多少。最后一行「一键清理」把四项一起处理。清理完成后页面会自动重新统计，并在下方显示这次释放了多少空间。

::: warning 清理不可撤销
删除的文件无法恢复。不过这几项都不含聊天记录、代码或配置，重新使用时会自动重建。
:::

## 占用偏大时怎么办

- **容器几个 G**：容器里的包管理器缓存通常是大头（如 Gradle、npm、pip 的缓存目录）。展开容器分类看是哪个目录最大，然后在终端里清理，例如 `rm -rf ~/.gradle/caches`。不再用的容器可以在「容器与镜像」页删除。
- **工作区偏大**：`node_modules`、`build`、`.gradle` 这类构建产物占大部分，删掉后重新构建即可恢复。
- **聊天记录偏大**：长会话里的工具输出最占地方，删掉早期不需要的会话即可。
- **镜像包还在**：容器已经装好后，「容器与镜像 → 下载镜像」页里可以删掉对应的下载文件。

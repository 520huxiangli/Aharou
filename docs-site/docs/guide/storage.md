# 存储空间

「设置 → 更多 → 存储空间」按类别展示 Aharou 在这台设备上占了多少空间，并提供清理临时数据的入口。

## 总览

页面顶部是应用总占用、构成条与设备剩余空间。构成条的整条宽度代表应用总占用，颜色与下方各分类的色点一一对应。页面底部固定显示「清理选中项」按钮及选中数据的大小，滚动列表时仍可操作。

统计需要逐个目录遍历文件，容器与工作区通常最慢。为了不让页面一直空着，各分类算完一个就显示一个，尚未算出的显示「—」，顶部会有「统计中…」提示。想重新统计点右上角的刷新图标。

## 占用明细

| 分类 | 包含什么 |
| --- | --- |
| 聊天记录 | 数据库文件：会话、消息、工具结果、调用记录、检查点索引 |
| 容器 | 各容器的根文件系统。展开可看到每个容器，以及占用最大的那个容器里最大的几个目录 |
| 容器镜像包 | 下载或导入的镜像压缩包。容器装好后它不再是必需品，但删掉后该容器无法再次解压 |
| 工作区 | 应用内置工作区里的项目文件（含 `.git`）。展开可看每个项目，副标题标出其中的聊天附件 |
| AI 配置与产物 | 技能、记忆、子代理、MCP 配置、提示词、文档，以及工具输出存档与识图会话缓存 |
| 离线语音模型 | 运行时下载到本机的离线语音模型（唤醒、流式识别、整句识别三份）副本（`filesDir/voice_models`），按模型逐项列出；删掉后下次用语音会重新下载 |
| 检查点 | AI 修改文件前留下的快照，用于撤销 |
| 日志 | 应用运行日志与 AI 请求日志 |
| 缓存 | 系统缓存目录，随时可清 |
| 其他数据 | 设置项、背景图、终端字体、SSH 私钥等零散数据 |
| 应用安装包 | APK 本体，不可清理 |

名称旁带箭头的分类点一下可以展开明细。「AI 配置与产物」仅展开显示可清理的工具输出存档与识图会话缓存；技能、记忆、提示词等不可清理内容不再逐项显示，但仍计入该分类的总占用。因此，展开的可清理子项之和可能小于分类总大小。

::: tip 哪些不计入
通过「添加本地目录」加进来的外部工作区在你设备的共享存储里，不属于应用占用，因此不统计。远程 SSH 模式下服务器上的文件同理。
:::

聊天记录的展开明细列出占用最大的几个会话。它是按消息正文估算的字节数，比数据库文件本身小——数据库还包含索引与页对齐开销。想减小这一项，去会话列表删掉不再需要的会话；只想清调用记录的话，在「Token 统计」页右上角重置。

容器和工作区不能在这里删除，请到「容器与镜像」页重置或删除容器、在工作区切换面板里删除工作区，避免误删正在用的环境。删除工作区会连同该工作区的聊天记录一并删除；外部本地工作区是否删除聊天记录，由「偏好设置」中的开关决定。

## 可释放空间

这一组里的五项都是可以安全删掉的临时数据或可重建的数据，但部分清理会影响历史内容的回看或追问。清理入口与占用明细放在一起，不再单独列出一组：

- **缓存文件**：勾选「缓存」分类。临时文件，之后会自动重建。
- **运行日志**：勾选「日志」分类。包含应用日志与 AI 请求日志，清空后新日志照常记录；点分类仍可展开查看两类日志的占用。
- **工具输出存档**：展开「AI 配置与产物」，勾选对应明细。AI 工具输出过长时会落盘一份完整副本。清掉后，历史消息里提到的输出路径不再能读取。
- **识图会话缓存**：展开「AI 配置与产物」，勾选对应明细。识图追问用的历史记录，清掉后无法再对旧图片继续追问；这两项只在有占用时显示。
- **离线语音模型**：勾选「离线语音模型」分类。本机已下载的唤醒、流式识别、整句识别三份模型，清掉后下次用到语音会自动重新下载（约 400MB，走国内镜像，建议在 Wi-Fi 下用一次语音让它下回来）。

日志与缓存默认选中，工具输出、识图缓存与语音模型默认不选。勾选后，底部按钮会更新选中项的合计大小；折叠分类不会取消选择。没有占用的项不可勾选，没有选中可清理数据时按钮不可点击。

点「清理选中项」后，确认框会列出清理目标、合计大小与各项影响。确认后只清理这些选中项，完成后页面会自动重新统计，并显示这次释放了多少空间。

清理范围是本机应用缓存、日志和全局目录中的数据，工具输出与识图缓存可能由多个工作区产生，不限当前工作区。不会清理各工作区自己的文件、附件、构建缓存或远程服务器数据。
::: warning 清理不可撤销
删除的文件无法恢复。虽然这些项不含聊天记录、代码或配置，但旧工具输出副本与识图会话历史无法通过重新使用恢复。
:::

## 占用偏大时怎么办

- **容器几个 G**：容器里的包管理器缓存通常是大头（如 Gradle、npm、pip 的缓存目录）。展开容器分类看是哪个目录最大，然后在终端里清理，例如 `rm -rf ~/.gradle/caches`。不再用的容器可以在「容器与镜像」页删除。
- **工作区偏大**：`node_modules`、`build`、`.gradle` 这类构建产物占大部分，删掉后重新构建即可恢复。
- **聊天记录偏大**：长会话里的工具输出最占地方，删掉早期不需要的会话即可。
- **镜像包还在**：容器已经装好后，「容器与镜像 → 下载镜像」页里可以删掉对应的下载文件。

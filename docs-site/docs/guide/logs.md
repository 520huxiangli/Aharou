# 日志与故障排查

App 出问题时，日志是最直接的线索。「设置 → 更多 → 日志」可以直接在应用内看。

## 应用内看日志

进去默认定位到今天的日志，页面上能做这些事：

- **日志等级**：顶部设置行显示当前等级，点击从底部面板选择（Verbose / Debug / Info / Warn / Error / None）。遇到 bug 时建议调成 `Debug`，日常保持 `Info`。正式版默认是 `Info`，过滤掉调试噪音。
- **切换文件**：点「日志文件」行从底部弹出日期列表，默认选中今天。
- **搜索与复制**：关键字实时过滤，右上角一键复制当前筛选结果。
- **彩色分级**：Verbose 灰、Debug 蓝、Info 绿、Warn 橙、Error 红。
- **单行复制**：点任意一行复制这条完整日志（含时间、等级、来源）；长按弹菜单可以选复制范围——本条、本条及堆栈、或只要消息内容。
- **实时滚动**：默认开启，每 3 秒自动刷新并跟随最新；关掉后停止刷新，保持你手动浏览的位置。

为了避免大日志卡顿，应用内只显示当前文件在筛选条件下的最后一部分，完整文件要去文件系统看。

## 日志文件在哪

```
/storage/emulated/0/Android/data/com.aharou.agent/files/logs/
```

不需要 root 权限，用手机自带的文件管理器就能打开。

工作区项目文件与 AI 配置存放在应用私有目录，普通文件管理器看不到，访问方式见[文件浏览与代码编辑](/guide/files#工作区文件在手机上的位置)。

## 按 MCP 名称过滤

排查 MCP 连不上的问题时，进「设置 → AI 配置 → MCP」，编辑某个服务器后点右上角的日志按钮，会跳到日志页并自动按这个服务器名过滤（页面顶部有过滤徽章，可一键清除）。列表页右上角的日志按钮则是看全部日志。

## 崩溃了怎么办

App 遇到未捕获的异常**不会直接闪退**，而是全屏显示一个崩溃错误页：

- 页面展示崩溃时的版本、设备、时间和完整堆栈。
- 点「复制错误信息」可以复制完整的崩溃报告（含堆栈和日志文件路径），直接粘贴发给开发者就行，不用自己翻日志。
- 可以选「重启应用」回到主界面，或者「退出应用」完全退出。

崩溃日志同样会落盘到上面那个 `logs/` 目录。

## 卡不卡？看性能分析

感觉发热、卡顿、掉电快时，「设置 → 更多 → 日志」能直接看到实时数据（日志页里能看到 CPU / 内存 / 流量），不用装第三方工具：

| 指标 | 说明 |
| --- | --- |
| 本应用 CPU | 本进程占用，已按核心数归一（8 核设备满负荷会显示 100%，不是 800%） |
| 整机 CPU | 设备整体占用。**部分系统版本上会显示「—」**，见下 |
| 线程数 | 本进程的线程总数（AI 在跑任务时会上涨，属于正常） |
| 本应用内存（PSS） | 本进程实际占的内存，包含容器等子进程 |
| 设备内存 | 总容量与可用量 |
| 本应用流量 / 整机流量 | 上下行速率，前者按 UID 统计 |

数据每秒刷新一次，只在**页面打开期间采样**——退出这个页面就停，不会一直在后台耗电。曲线展示最近一段时间的走势，量程会随实际峰值缩放。

**整机 CPU 显示「—」是正常的。** Android 10 起，系统不再允许普通应用读取 `/proc/stat`（权限拒绝）。这里如实显示「—」而不伪造一个 0%，因为「读不到」和「真的空闲」是两回事。

## 长任务切后台被中断怎么办

如果 AI 执行长任务（如编译、深度代码审查）或终端运行耗时命令时切到后台经常被杀掉，请前往「设置 → 权限与后台 → 软件权限」开启**后台运行保活**、**忽略电池优化**与**自启动管理**，详见[软件权限](/guide/app-permissions)。

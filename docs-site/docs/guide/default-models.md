# 默认模型

「设置 → 默认模型」里除了新会话使用的默认模型，还可以给几个特定用途单独指定模型。

## 语音识别与合成模型

这里有两行：**语音识别（听懂你说的话）**和**语音合成（念出 AI 回复）**。当前真正在用的是合成，识别走的是随安装包自带的离线模型。

- **语音识别（STT）**：用于把你说的话转成文字，但目前**当前 UI 未开放**——输入栏的麦克风按钮只负责开关语音通话，不读这里的云端设置（通话固定用随包自带的离线识别模型，不用联网，见下面的「离线语音模型」）。这一行留着给后续的语音输入入口。
- **语音合成（TTS）**：朗读与语音通话都用它出声。**不配也能用**——自动回退到手机自带的语音引擎，零配置就能念，音质与断句不如云端。选好供应商与模型后，还可以单独指定**音色**。

这两行下方还有两行：**自动朗读**开关与**离线语音模型**状态。

**自动朗读**开关：打开后每条 AI 回复都自动念出来，**边生成边念**（攒够一整句就开口，不等回复写完）。用法详见[语音通话与朗读](/guide/voice)。

**离线语音模型**：语音唤醒、语音通话识别用的模型随安装包自带（三份：唤醒词检测、流式识别、整句识别），**不联网下载**。这一行显示它们当前的状态：

- **已就绪**：模型完整，直接能用。
- **缺失 / 大小不符（文件名）**：磁盘上的模型不完整（一般是旧版本残留或释放中断）。点右边的**重新释放**，App 会从安装包里把三份模型都重新释放一遍覆盖掉坏的，点完不用重启。
- 如果重新释放后仍然异常，说明安装包里的模型不完整（开发构建漏拉模型时会这样），重装完整的安装包即可。

## 识图模型

决定 AI 用哪个模型看图片。

- **跟随当前聊天模型**（默认）：用你当前选中的聊天模型看图。
- **指定专用模型**：固定用某个模型看图，不随聊天模型切换。适合聊天用的模型不支持图片、或者你想用更便宜的模型处理图片的情况。

列表里每个模型旁边会标注是否支持图片输入，供你参考。注意这里**不做强制拦截**：如果你选了一个不支持图片的模型，识图会失败，AI 会收到错误信息并自行处理（通常会提示你换一个模型）。

识图的用法上有两点值得知道：

- AI 一次最多可以给识图模型 4 到 5 张图做对比分析，之后还能在同一个识图会话里继续追问，识图模型记得之前看过的图和问答。
- 图片默认会按需压缩以节省 token，也可以要求原图直传或更省 token 的低清模式。

还有一个开关：**为无视觉模型识别图片**（默认开启）。聊天用的模型不支持图片输入时，图片与影子屏截图会先用**本机 OCR** 转成文字再发给模型，让它至少能读到图上的字。全在本机识别、不上传图片，适合 DeepSeek 这类纯文本模型配影子屏用。

两个 OCR 使用位置有主次之分：平时靠这个开关自动兜底；「识图模型」指定了专用模型时，就优先走那个模型做真正的图像理解（OCR 只认字，认不了画面内容）。

## 生图模型

设置 `generateImage` 工具使用的模型，支持 OpenAI 和 Gemini 兼容接口。

- OpenAI 兼容接口支持尺寸、数量、画质、背景、风格和输出格式等参数。
- Gemini 兼容接口使用模型默认尺寸与分辨率；生成多张图片时会调用多次。
- 图片默认保存到 `~/.aharou/generated-images/`，也可指定工作区路径。单张图片上限 20MB，单次调用总计上限 48MB。

## 图像模型对话生图

通过 Gemini 兼容接口接入支持图像输出的聊天模型后，可直接生成图片、上传参考图，并在后续对话中继续修改生成结果。

## 标题总结模型

新会话发出第一条消息后，Aharou 会自动给会话生成一个标题。这里可以指定专门干这件事的模型。

- **跟随当前聊天模型**（默认）。
- **指定专用模型**：建议选一个便宜快速的小模型，标题这种活不需要好模型。

标题生成在后台异步进行，不会拖慢你的对话。如果生成失败或者取不到结果，会保留系统按首句截断的临时标题，不影响使用。

生成标题用的提示词也可以自己改，方式见「自定义提示词」。

## 压缩模型

会话上下文占用到窗口一定比例时会自动压缩（比例在「偏好设置 → 模型」里调，也可以手动执行 `/compress`），这里指定压缩时用哪个模型。

- **跟随当前聊天模型**（默认）。
- **指定专用模型**：压缩会把早期对话整理成一份接手摘要，选个便宜快速的模型就够了。
- 也可以**整组选择**：选一个模型组时，实际用到的模型按组内成员顺序取用，见 [模型组](/guide/model-groups)。

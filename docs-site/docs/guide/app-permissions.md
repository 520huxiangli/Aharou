# 软件权限

「设置 → 权限与后台 → 软件权限」集中管理 App 需要的系统级权限。权限状态在页面恢复时（包括从系统设置页返回）自动刷新，已授权的项点了不会有反应。

后台保活、屏幕常亮、AI 完成通知这三个开关在[后台运行](/guide/background-run)页。

## 运行时权限

页面最上面一组，六个需要你逐项授权的常见权限：

| 项 | 用途 |
| --- | --- |
| 相机 | 拍照 / 扫码等视觉能力 |
| 麦克风 | 语音输入 / 录音 |
| 位置 | 获取当前位置（精确定位） |
| 通讯录 | 读取联系人 |
| 日历 | 读取日程 |
| 电话状态 | 读取设备与通话状态 |

未授权的行点一下会弹系统的权限申请框；如果系统已经不再弹框（之前选了拒绝且不再询问），会跳转到本应用的详情页让你手动开。本组最后一行是**一键申请全部运行时权限**，点了会把还没授予的一次性全申请一遍。

## 特殊权限与白名单

中间一组，都是不能靠普通申请弹窗拿到的权限。点行会跳到对应的系统设置页，行尾显示当前状态（部分行只显示「去设置」）：

- **悬浮窗**：在其他应用上层显示（状态胶囊），见[无障碍与悬浮窗](/guide/accessibility)。
- **所有文件访问**：访问整个存储空间（Android 11 及以上才显示这一行）。
- **修改系统设置**：允许改动部分系统设置项。
- **电池优化白名单**：跳到系统的白名单页，可查看 / 管理全部应用的电池优化白名单。
- **使用情况访问**：读取应用使用统计（统计 / 自动化用）。

下面从「安装未知应用」开始的几项属于页面最后一组「系统权限」。

## 安装未知应用

显示当前是否已允许。未允许时点这一行会跳到系统设置里本应用的「安装未知应用」开关页，开启后才能安装 APK。

## 访问存储空间

用于读写工作区文件与容器镜像。

- **Android 11 及以上**：这一行显示的是「所有文件访问」的授权状态，未授权时点击会跳到系统设置里对应的开关页。用「添加本地目录」把设备存储上的目录加成外部工作区、以及让 AI 直接读写这些目录，都依赖这个权限。
- **Android 10 及以下**：未授权时点击弹系统的存储权限申请框；已被永久拒绝（系统不再弹框）时会有弹窗提示，点「去设置」手动开启。

## 忽略电池优化

显示当前是否已豁免。未允许时点击跳到系统的电池优化申请页，对本应用豁免省电策略，降低后台进程被杀的概率。

## 自启动管理

点击跳到你设备厂商（小米、华为、OPPO、vivo、魅族等）的自启动管理设置页，允许 App 在开机或被杀后由系统自动拉起。厂商设置页打不开或者匹配不到厂商时，会回退到本应用的详情页。

这一项配合「后台运行保活」和「忽略电池优化」一起用，能进一步降低后台被杀的概率——国产 ROM 上后台限制比较激进，跑长任务经常被打断的话，三个都开。

## root 权限

设备已 root 时，授予本应用 root 权限后，AI 的宿主命令会以 uid 0（最大权限）执行，不再依赖 Shizuku。这一行显示当前状态：

- **未检测**：点击检测本机是否已授予 root 权限。
- **未授权**：先在 root 管理器（Magisk / KernelSU 等）里给本应用授权，再点这一行重新检测。
- **已授权**：宿主命令将以 uid 0 执行。

没 root 的设备保持「未授权」即可，不影响任何功能。

## Shizuku 授权

Shizuku 让本应用以 adb shell（uid 2000）身份执行系统命令，是 AI 的 `Shizuku` 工具的前提（没有 root 时走这条）。这一行显示当前状态：

- **未安装 / 服务未运行**：点击打开 Shizuku 应用，按其中的指引安装或启动服务。
- **未授权**：点击申请授权，在 Shizuku 弹出的授权框里选「允许」。
- **已就绪**：授权完成，AI 即可调用 `Shizuku` 工具。

## 当前执行通道

显示此刻实际用的是 `root` 还是 `Shizuku`——两条通道 **root 优先**，都不可用时显示「不可用」。

从 Shizuku 应用或系统设置返回本页时状态会自动刷新。用法与安全注意事项见 [宿主执行后端](/guide/shizuku)。

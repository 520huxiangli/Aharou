# 模型组

模型组是把几个模型收进一个具名列表：需要选模型的地方可以**整组选择**，执行时按成员顺序取用。

入口：「设置 → AI 配置 → 模型组」。

## 建一个组

1. 点「新建模型组」，填名称（不能为空），保存后直接进入这个组；
2. 在组详情里点「添加成员」，从**已启用且已配模型**的供应商里挑，点一下即加入；
3. 成员按顺序取用，用「上移 / 下移」调整；首成员不能上移、末成员不能下移；
4. 「重命名」「删除」在详情页顶部。删除后，选过这个组的地方需要重新选模型。

同一个模型在组里只会出现一次（重复添加会被忽略）。

## 组能用在哪

目前**只有「默认模型」页的四个角色能整组选择**：

- 识图模型
- 压缩模型
- 标题总结模型
- 生图模型

选了组之后，这一行显示「组：<组名>」，实际执行时用组里的**第一个成员**。

主页的聊天模型选择器、子代理编辑器目前**不能**选组，只能选具体模型。

## 几点说明

- 执行时只取组内**首个成员**，后面的成员暂时只是备用名单——顺序很重要，把最稳的模型放第一个。
- 组里还没有成员时，选了它等于没选到模型，先把成员加齐再用。
- 组名只要求非空，长度不限；成员数量也没有上限。
- 成员来源是「已启用」的供应商，供应商或模型停用后，这个组里对应的条目就用不上了。

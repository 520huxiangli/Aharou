# 设备能力

让 AI 用上手机本体：建闹钟、查日程、找联系人、读剪贴板、定位、看天气、控制媒体、读通知、看相册。这些都在 `device` 工具里完成，**不需要 root，也不需要 Shizuku**。

短信、通话记录与应用使用统计更私人，单独归「个人数据查询」管，见下面的[个人数据查询](#个人数据查询)。

## 能做什么

| 能力 | 说明 | 需要什么 |
| --- | --- | --- |
| 建闹钟 / 计时器 | 交给系统时钟去建，跟你手动设的完全等价：杀进程照样响、省电模式照样响 | 无 |
| 日历 | 看某段时间的事件、新建事件 | 日历读写权限 |
| 联系人 | 按名字或号码找、新建联系人 | 通讯录读写权限 |
| 剪贴板 | 读 / 写剪贴板 | 无（读取要求 Aharou 在前台） |
| 定位 | 取当前位置与地址 | 位置权限 |
| 天气 | 今天天气（可指定城市，不给就用当前位置） | 无需权限；气温数据来自 Open-Meteo |
| 媒体控制 | 播放 / 暂停 / 切歌 / 调音量 | 无 |
| 通知 | 读最近的通知、发一条通知、在通知里直接回复 | 读和回复需要「通知使用权」；发需要通知权限 |
| 设备信息 | 机型、系统版本、电量、存储、内存、网络 | 无 |
| 相册 | 最近图片的文件名、时间、尺寸、路径 | 相册读权限或「所有文件访问」 |
| 短信 | 按时间看最近的短信（号码、正文、收发类型），可按号码或正文筛选 | 短信读取权限 |
| 通话记录 | 按时间看最近的来电 / 去电 / 未接（号码或联系人名、时长），可按号码或名字筛选 | 通话记录读取权限 |
| 应用使用统计 | 按应用汇总前台时长，或看最近应用在前台 / 后台之间切换的记录 | 「使用情况访问」特殊权限 |

## 怎么用

直接说人话就行：

- 「明早八点叫我」→ 建系统闹钟
- 「看看我今天的日程」→ 读日历
- 「刚复制的东西翻译一下」→ 读剪贴板
- 「我在哪」→ 定位
- 「今天要带伞吗」→ 天气
- 「暂停一下音乐」→ 媒体控制
- 「刚才谁给我发消息了」→ 读通知
- 「回他一句马上到」→ 在通知里直接回复
- 「最近拍了什么照片」→ 相册
- 「昨天我妈给我发短信了吗」→ 查短信
- 「昨天那通电话聊了多久」→ 查通话记录
- 「我今天都在用哪些 App」→ 查应用使用统计

它也能被自动化任务调用，例如「每天 8:00 提醒我今天的日程」。

## 需要开的权限

无权限的几项（闹钟、剪贴板、媒体、设备信息、天气）开箱即用。其余的按需开启，入口都在「设置 → 软件权限」（短信与通话记录例外，见下面「个人数据查询」）：

- **日历 / 通讯录 / 位置**：运行时权限，点一下授权即可。
- **相册**：Android 13 及以上要「照片和视频」权限；也可以直接给「所有文件访问」。
- **通知使用权**：这是系统级的特殊权限，**只能由你在系统设置里手动勾选**（通常路径是「设置 → 通知 → 通知使用权」，部分机型叫「通知读取权限」）。应用无法自己申请。
- **通知发送**：需要系统「通知」权限。

没开权限时工具不会崩，而是返回一段明确的开启指引，把那段话照着做即可。

## 注意

- **剪贴板读取要求 Aharou 在前台**：这是 Android 10 起的系统限制，后台读不到内容（返回空）。
- **通知读取只看开启之后的**：开启「通知使用权」之前收到的通知读不到，缓存里只保留最近 50 条，且应用退出后清空。
- **直接回复通知**：微信、QQ、Telegram 这类通知自带回复框的应用，AI 可以把你要说的话填进那条通知的回复框发出去，不用打开对应应用。前提是先开好「通知使用权」，而且那条通知还在通知栏里；通知本身没有回复框（比如系统提醒、部分应用的通知）就回不了，划掉之后也回不了。AI 只在你明确说了要回、回什么的时候才会发；非自动模式下发出前还会弹授权确认，自动模式下直接发出。
- **定位取的是「最后已知位置」**：不做持续定位，所以可能略有延迟；刚开机或久未定位时可能拿不到，给天气指定城市是更稳的用法。
- **建闹钟依赖系统时钟应用**：极少数精简 ROM 没有时钟应用时会失败并给出提示。

## 个人数据查询

短信、通话记录与应用使用统计这三样比上面那些更私人，单独走一条路：**先问权限、再按当前任务查，只读、随时能收回**。

### 会看到什么

- **先报权限状态**：正式查询前，它会先告诉你这几项现在能不能用——可用、只授权了一部分、没开、被系统或安装来源锁死、这台机器上根本没有对应的数据服务。没开的会顺带告诉你去哪儿开。
- **默认只看最近 7 天**：说「最近谁给我发过短信」时按 7 天算；要往前翻就明确说「最近 30 天」（最长 30 天，再往前查不到）。
- **一次给一页**：默认一页 50 条（最多 200 条）。问得宽时它会分批取，或者先答一段再接着查下一段；追问「还有吗」就会继续往下翻。
- **短信**：号码、正文、收发类型（收到 / 发出 / 草稿等）、时间、是否已读。超长的短信只带正文前面一段（约 500 字），后面的内容会被略过。
- **通话记录**：号码、联系人名（系统里有记录时才带）、来电 / 去电 / 未接等类型、时长、时间。
- **应用使用统计**：按应用汇总时给应用名、前台时长、最后一次使用时间；也可以改看最近的应用切换记录。系统本身是按天汇总的，所以时长是近似值。

### 权限在哪开

- **短信、通话记录**：系统的运行时权限，要到「系统设置 → 应用 → Aharou → 权限」里把「短信」「通话记录」设为允许。应用内的「软件权限」页不提供这两项的单独开关。
- **应用使用统计**：「设置 → 权限与后台 → 软件权限 → 使用情况访问」，点这一行会跳到系统的「使用情况访问」页，在列表里勾选 Aharou。刚开完系统要过几分钟才有数据，查不到可以先等一会儿再问。

没开权限时不会失败：它会回一句「要开哪个」的说明，照着开好再让它查一次就行。

### 边界

- **不逐次弹确认框**：授权一次之后，查短信 / 通话记录 / 使用统计不会每查一次都弹「确认操作」——门槛就是系统权限本身。想彻底禁掉，就去系统设置里把对应权限关掉。
- **只读**：读短信、读通话记录、读使用统计，**从不**发短信、拨号、改已读状态或删记录。
- **随时收回**：在系统设置里关掉权限后，下一次查询就会被告知不可用，不会在后台继续采集。
- **被系统锁死时开不了**：少数国产 ROM，或者从某些应用商店装的包，会把短信 / 通话记录权限锁死，连系统权限页都打不开。遇到这种它会直接说明「开不了」，让你换个办法。
- **查不到不等于没有**：个别 ROM 不提供短信库 / 通话库，或者不允许第三方读取，这时它会明说这一点，而不是回你一句「没有记录」。
- **这些内容会进入这一轮对话**：它被要求只按当前任务查询、不为「先看看」批量拉取，也不把查到的内容归档进长期记忆或替你转发给别人；但内容和你自己打的字一样会随本轮对话发给模型。不想留痕可以开[隐身对话](/guide/chat#隐身对话)。

# 关于与更新

「设置 → 帮助与关于 → 关于」显示应用信息，也是检查更新的入口。

## 版本与检查更新

顶部卡片显示 App 图标、应用名和一句简介，下面的「版本」行显示当前版本号。

**点版本行手动检查更新**：会去 GitHub 的发布列表查有没有更高版本（按你选的更新通道过滤）。有新版本时弹窗显示「发现新版本」，并列出**从你当前版本到新版本之间的全部更新日志**。

弹窗主按钮是「**下载并安装**」：点了就在应用内直接下载，弹窗里显示实时进度和当前用的下载源（**GitCode 镜像** / **GitHub** / **加速镜像**，按可用性依次尝试），下完自动拉起系统安装器，装完 Aharou 重启、对话记录保留。下载中可以点「取消下载」。

只有在**所有内置下载源都失败**时，按钮下方才会出现「**用浏览器打开**」作为兜底，跳转到那个版本自己的 Release 页面手动取 APK。

已经是最新版本会提示「已经是最新版本」；网络失败会提示「检查失败」并给出错误信息。

## 自动检查更新

默认开启。打开 App 进主页时在后台异步检测，**每天最多一次**（当天检测过就不再重复）。发现新版本会自动弹更新窗，网络失败时静默处理不打扰你。

关掉之后不再自动检测，但手动点版本行仍然可以检查。

## 自动下载更新

默认开启。检测到新版本后，App 会在后台用国内镜像把安装包提前下好，等你要更新时只需点一次「立即安装」，不用现下。

关掉后只在弹出更新窗、你点「下载并安装」时才开始下载。

## 下载后自动安装

默认关闭。开启后，安装包下完就直接拉起系统安装器装上，不用你点任何按钮。

这一项需要 **Shizuku 授权**（见 [Shizuku 执行后端](/guide/shizuku)）。注意装完会重启 Aharou，而且 Android 不允许降级安装，**无法回退到旧版**，想稳当就保持关闭。

## 更新通道

默认「正式版」：

- **正式版**：只检测正式版，测试包一概不出现。
- **测试版**：只检测测试包（含 beta 与 RC 预览版），正式版不会出现在这里。

**测试版**是每次 master 有新提交时自动构建的包（与正式版同签名同配置，只多一个包名后缀，可与正式版同机共存），用它可以第一时间试到刚做好的改动。预览版（RC）是发版流程里的候选包，相对少见。

两个通道各管各的，不会交叉：图稳定选正式版，想试新东西选测试版。切通道后点版本行手动检查一次即可。

## 其它入口

- **GitHub 仓库**：用系统浏览器打开源码仓库。
- **开源许可证**：本项目使用 GPL-3.0，点击打开完整的 LICENSE 文件。

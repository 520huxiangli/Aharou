# 技能

技能是为 AI 提供的「专项能力扩展包」——把某类任务的标准流程、最佳实践与专属知识沉淀为规范指南，AI 遇到相关任务时会自动按需加载执行，无需你在每次对话中反复交代背景规则。

入口在「设置 → AI 配置 → 技能」。已启用的技能会出现在对话输入框的 `/` 菜单里，可以直接用 `/技能名` 触发，也可以带参数（如 `/pdf-report a4`），详见[对话与消息](./chat.md)的〈斜杠命令〉。

## 技能从哪里来

一个技能就是一个目录，里面有 `SKILL.md`（或兼容的 `CLAUDE.md`）就会被自动识别。分三级：

- **内置技能**：随 App 打包，开箱就有（如配置通道说明、第三方 App 操作规范、面板脚本编写）。**不能删除也不能编辑**，列表里带「内置」徒标，也不参与启停。
- **全局技能**：放在 `~/.aharou/skills/`，跨项目共享，App 升级不丢。
- **项目级技能**：放在 `<工作区>/.aharou/skills/`，只在当前工作区生效，可以随项目提交到 git。远程模式下这里指的是**服务器上**的工作区，读写经由 SSH 完成。

同名技能优先级：项目级 > 全局 > 内置。

你可以直接在 App 里新建技能（见下文），也可以从技能市场安装（见下文），或者在容器里手工创建技能目录。本地模式下 App 会监听技能目录，手工添加、删除、改名之后列表几秒内自动刷新，不用重进页面。远程模式下不会监听服务器上的文件变化，手工修改后需退出并重新进入设置页刷新列表。

## 列表页

按「内置 → 当前项目 → 全局」三个可折叠分组显示，点分组标题展开或收起；内置组随 App 打包，不提供删除入口（连左滑手势都不接）。

每行是一个技能：图标、名称、描述摘要，名称右侧的彩色勋章表示启用或禁用状态。点行进详情；左滑露出删除按钮，删除会弹确认框——它会直接移除技能目录，**不可恢复**。

**长按任意一行**弹出操作单：移动（全局 ⇄ 当前项目）与导出，就地办完不用进详情页。内置技能随 App 打包，操作单里只剩「导出」——它既不能搬地方，也不能删（删除仍走左滑）。

右上角「＋」添加技能（见下文〈添加技能〉）。

## 添加技能

点右上角「＋」弹出底部选择单，先选**作用域**（全局 / 当前项目，默认全局），再选添加方式：

- **手动新建**：进入编辑页，填写名称、描述与正文，从头建一个技能。
- **从文件导入**：选择一个 `.md` 文件（`.markdown` / `.txt` 也可）。App 读取文件内容，按其 frontmatter 的 `name`/`description` 建技能，缺 `name` 时用文件名兜底，写入 `<作用域>/skills/<名称>/SKILL.md`。
- **从压缩包导入**：选择一个 `.zip`。App 解压后识别包内所有含 `SKILL.md`（或 `CLAUDE.md`）的目录，逐个导入——一个包可以带多个技能，常见于 GitHub 仓库的打包下载。
- **从市场安装**：进入技能市场挑选并安装（见下文〈技能市场〉）。

导入与手动新建等价：文件一律归一化为 `SKILL.md` 落盘，之后照样能用编辑器或容器命令改。

**几种会被跳过的情况**（会弹窗逐个列出原因，不影响其余技能）：

- 技能名称不合法（含 `/` `:` 等不能做目录名的字符、为空或过长）；
- 目标作用域下已有同名技能（不会覆盖）；
- 技能正文为空；
- 压缩包里没有任何含 `SKILL.md` 的目录（整体失败）。

## 详情页

三张卡片：「是否启用」（卡片里有启停开关与存放位置）、「摘要」（描述）、「指令正文」（以 Markdown 渲染显示；要改原文进编辑页的指令正文栏）。技能名显示在顶栏。

「是否启用」卡片下半部分是**存放位置**：显示这个技能在「全局」还是「当前项目」，右侧按钮点一下就搬到另一边。搬动是整包搬过去的——技能目录下的全部文件（含附带的脚本）一起走，原位置不留副本；搬完列表刷新，搬运结果会弹一条提示。

两件事会拦住搬动：

- **目标位置已有同名技能**——不覆盖，直接在原位置不动；
- **内置技能**——随 App 打包，不可搬（那张卡片对内置技能整个不显示）。

内置技能没有启停开关，也没有编辑按钮。

右上角的铅笔按钮进入编辑页。

### 导出

详情页的「导出」把这一个技能打成 zip（里面是该技能目录下的全部文件，包括附带的脚本），完成后弹系统分享面板——可以存到文件管理器、发给别人，或者留个档。

打包结构与「从压缩包导入」认的格式一致，所以导出的 zip 能直接导回来，也能装到别的设备上。内置技能同样可以导出（正文从 App 内置资源现攒一份 `SKILL.md`）。

## 新建与编辑

编辑页有两组内容：

- **基本信息**：名称、描述、作用域。名称就是 AI 加载技能时用的标识，建议用英文小写加连字符（如 `pdf-report`）；描述写「何时该用它」，AI 靠这句话判断要不要加载；作用域选「当前项目」或「全局」，决定技能目录落在哪一级。
- **指令正文**：技能的完整指令，支持 Markdown。写清这类任务的标准流程、约束与注意事项。

名称和正文都填了才能点右上角「保存」。保存后会写成 `<技能目录>/SKILL.md`，与手写的技能完全等价，之后照样可以用文本编辑器或容器命令改。

几个需要留意的地方：

- **编辑页里的作用域只在新建时选**。已有技能在编辑页里是灰的（改名不动目录）；**换作用域到详情页的「存放位置」行点一下就行**。
- **改名只改 `SKILL.md` 里的 `name`，不动目录名**。技能正文里常按 `~/.aharou/skills/<目录>/run.py` 引用同目录脚本，目录跟着改名会把这些引用打断。
- 编辑的是从 GitHub 装来的技能时，如果它用的是 `CLAUDE.md` 而不是 `SKILL.md`，保存会写回原来那个文件，不会多出一份。
- 同一作用域下已有同名技能、名称含 `/` `:` 等不能做目录名的字符、或正文为空时，保存会失败并在页面顶部给出红色提示。

## 技能市场

入口：设置 → AI 配置 → 技能 → 右上角「＋」→ **从市场安装**。装上的技能就是一个普通技能，可以编辑、禁用、删除。

预置了四个源：Aharou 官方、Claude 技能大全、科学技能集、腾讯 WorkBuddy（自己贴过仓库地址时，那个仓库会排在第一个）。点源名切换，列表里显示该源技能的名称、描述与作者、版本、许可、安装量，右侧是「安装」（已装过显示「已安装」，有新版显示「更新」）。源标签保持一行，放不下时左右滑。

列表上方可选排序：**默认**（按源里的顺序）、**名称**、**热门**（按安装量，只有检索型源带得到这个数）。

**换源与刷新**：换源时列表先清空再拉新的——腾出来的地方会显示「加载中」，不会把上一个源的技能留在屏幕上冒充新源（WorkBuddy 有两百多个技能，首次拉取要等十几秒，前几条先出、描述随后补上）。每次拉到的列表会本地缓存 12 小时，想立刻重拉有两个方式：右上角的刷新按钮，或再点一下当前选中的源名。整页进详情再返回时停在原位置，不会跳回第一条。

**点任意一条进详情页**，装之前先看清是什么：

- 顶上是技能名、标识与描述，下面是来源仓库、作者、版本、许可、安装量；
- **技能说明**：源里那份 `SKILL.md` 的原文，整篇可选中复制（常要抄里面的命令）；源只以整包分发、取不到正文时会给一句说明；
- **文件清单**：这个技能目录下有哪些文件（超过 30 个只列前 30 个）；
- **装之前看一下**：技能包里带了哪些可执行脚本、用起来是否需要密钥或令牌。这两项只按文件名与正文关键词判断，报的是「有什么」而不是「危不危险」，装不装还是你定；
- 底部选作用域后点「安装」（已装的显示「重新安装」，有新版显示「更新到最新」）。

其中「Aharou 官方」里的技能是我们自己写的，随 App 仓库更新；**「面板脚本编写」已改为内置**（不在此列，随 App 打包，市场里装不到也不提供启停）。

| 技能 | 用来干嘛 |
| --- | --- |
| 自身故障排查 | App 崩溃/卡顿、AI 请求反复失败、连不上服务器时，先看日志定性的流程 |
| 宿主设备管理 | 用 shell 身份装/卸应用、抓 logcat、截屏、跑 dumpsys |
| 容器环境初始化 | 首次进容器、换软件源、装 Node/Python/JDK，以及已知坑 |
| 子代理编排 | 何时派子代理、prompt 要怎么写、自定义子代理定义 |

这些是「按需装」的：不装就不会占用任何上下文，装完 AI 在对应场景才会加载它。

**粘贴仓库地址**：顶部输入框可以直接贴仓库地址，从里面挑技能装，支持：

- GitHub：`github.com/某人/某仓库`
- Gitee：`gitee.com/某人/某仓库`
- GitLab：`gitlab.com/某人/某仓库`
- Gitea / Forgejo 等自建实例（按域名识别）
- 简写 `某人/某仓库`（按 GitHub 处理）

带上分支和子目录也行：`github.com/某人/某仓库/tree/main/skills/docx` 会只扫 `skills/docx` 那一层。**仓库里凡是含 `SKILL.md` 的目录都会被列出来**，所以整个仓库有多个技能时会一次列出；整个仓库就一个技能（`SKILL.md` 直接放在仓库根目录）时也认得出来。

加载之后这个地址不会白填：下面关键词框的搜索会**只在这个仓库里筛**（详见〈关键词搜索〉）。自己贴的仓库会排在源标签行的第一个，标签上就是 `某人/某仓库`，想回看它的完整列表点一下就行。

技能网站的地址也认：

- `skills.sh/某人/某仓库`（带技能名也行，如 `skills.sh/anthropics/skills/pdf`）—— 直接换算成它背后的 GitHub 仓库
- `lobehub.com/skills/某技能` —— 先读一次那个技能页，找出它的仓库再列

技能网站给的技能名不一定等于仓库里的目录名（skills.sh 的 `/anthropics/skills/pdf` 在仓库里其实是 `skills/pdf`），所以按子目录没扫到时会自动退回整个仓库，从列表里挑就行。

**站点的目录页地址**（如单独的 `skills.sh`、`lobehub.com/skills`）拿不到技能清单——它们没有「列出全部技能」的公开接口，会提示你贴到具体技能或仓库那一级。

## 关键词搜索

页面上有两个常驻的输入框：**上面的填网页地址（点「加载」），下面的填关键词（点「搜索」）**。关键词去哪搜，看上面的地址框填没填：

- **填了地址** → **只在这个仓库里搜**：在已列出的技能里按名称 / 描述就地筛，走本地、不联网，同一个地址再搜不会重复拉取。
- **没填地址** → **只在当前选中的源里搜**：同样在已拉到的列表里就地筛，也就是说搜的是上面那排源标签里选中那个。列表还没出来时会提示「稍等一下再搜」。

**关键词至少 2 个字**，不够按钮是灰的。搜索不发网络请求，结果即时出来；想回到完整列表，点一下当前选中的源名（或右上角刷新）。

搜完想看回某个源的完整列表，点那个源标签就行——自己贴的仓库排在标签行第一个（标签上就是 `某人/某仓库`），点一下会重新拉出它的完整列表。

**中英文显示与自动翻译**：市场按 App 界面语言挑仓库里对应语言的字段——WorkBuddy 这类国内仓库自带中文（`description_zh`），直接显示中文。仓库只给英文的（Claude 技能大全、科学技能集大多如此），列表会**自动翻成中文**：只送没有中文的条目、每批 20 条在后台翻、翻好一批换一批（中文名在上，英文标识仍留在下面小字里）。译文按「仓库@技能目录」存在本地（`~/.aharou/skill-translations.json`），**同一条只翻一次**，换源、重启都不会重花你的 token。用的是当前生效的模型（配了「标题总结专用模型」就用那个）；模型没配、网络不通或翻失败时直接显示英文原文，不弹错、不挡你装。

技能多的源（比如 WorkBuddy 有近三百个）会**先把技能名铺出来、描述随后补上**，不用等全部读完才看到列表。

列表优先显示仓库自带的中文名与中文描述（`display_name` / `description_zh`，WorkBuddy 这类国内仓库都带了）；仓库没提供中文时按界面语言回退。显示名与技能标识不同时，标识会另起一行小字放在下面——调用技能、排查问题时认的是它。

访问 GitHub 走的是加速通道，不用自己挂代理；如果连不上会明确提示「加载失败」，跟「这个源里没有技能」是两种提示，不会混淆。

装到全局还是当前项目，由**技能页右上角「＋」里的「作用域」**决定（市场页不再单占一行，这个选择与市场安装共用）。**同名技能会被覆盖更新**——在技能市场里点「安装」就是对「更新」的语义。

列表结果会缓存 12 小时，再次进入同一个源秒开（目录型源要逐个读每个技能的 `SKILL.md`，不缓存每次进来都要重跑）。想立刻重拉就点右上角的刷新。

> 市场里的技能来自第三方仓库，安装前留意作者与许可信息；有些技能是 source-available 许可，不是开源，用前先读它的许可条款。

**自己加源**：除了预置源，还可以通过配置通道加自定义源（路径 `skill_market.sources`）。新增一项需要 `id` / `repo` / `path`，可选 `branch`（默认 `main`）、`kind`（`directory` 扫目录 / `index` 读 JSON 索引，默认 `directory`）、`host`（`github` / `gitee` / `gitlab` 或 Gitea 系域名，默认 `github`）。

## 启用与禁用

详情页的开关控制这个技能是否参与 AI 会话。禁用后它不再出现在系统提示的可用技能清单里，AI 也无法加载，可以减少上下文占用——技能装多了之后这个开关很有用。

禁用名单写在 `skills.json` 里：全局名单位于当前执行环境的 `~/.aharou/skills.json`，本地模式保存在手机 App 私有目录，远程模式保存在服务器上；两者独立，不会自动迁移或同步。项目级名单在本地模式位于 `<工作区>/.aharou/skills.json`，远程模式仍保存在手机 App 私有目录，按服务器和工作区隔离。格式是：

```json
{ "disabled": ["技能名"] }
```

两级取并集，任一作用域禁用即生效。也可以直接手工编辑名单，下次读取时生效；本地模式下列表几秒内自动刷新，远程模式下手工修改服务器上的名单后需退出并重新进入设置页刷新列表。

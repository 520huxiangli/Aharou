# 语音通话与朗读

语音功能有两条独立的链路，都从输入栏的**麦克风按钮**开始：

- **语音输入**：把你说的话转成文字填进输入框，然后照常发送；
- **语音通话**：全程免手，AI 边说边听，适合不方便看屏幕的时候。

此外 AI 的每条回复都能**念出来**（朗读），可以手动点，也可以让它自动念。

::: tip 首次使用
语音识别优先走你配置的识别模型；没配也能用——会自动回退到设备本地的识别能力，只是准确率和速度差一些。朗读同理，没配语音合成模型时会用手机自带的语音引擎念。
:::

## 语音输入（按住说话）

**按住**麦克风按钮说话，松手后识别出的文字会填进输入框，你确认或修改后再发送。

- 录音时间过短会被忽略；
- 识别过程在输入框上方实时显示，可以中途取消；
- 环境太吵或说话太轻时可能提示「录音近乎静音」，凑近一点再说。

## 语音通话（轻点开关）

**轻点**麦克风按钮即开启通话，通话中图标会变成主题色。再轻点一次结束。

开启后进入**免手循环**：

1. 它开始听你说话（悬浮窗头像外圈会出现一圈亮环，表示正在听）；
2. 你说完停顿一下，它自动把这句话发出去，不用点发送；
3. AI 回复时**一边生成一边念**，不用等整段写完；
4. 念完继续听下一句。

**它不会自己挂断** —— 要结束就再点一次麦克风按钮。

### 悬浮窗上的字幕与展开

通话期间，状态胶囊悬浮窗会一直显示，上面能看到谁在说话：

| 位置 | 含义 |
| --- | --- |
| 头像外圈亮环 | 正在听你说话 |
| 第一行「语音通话」 | 当前处于通话中 |
| 第二行 | **谁在说就显示谁的话**：它念到哪句显示哪句，没有就显示你正在说的内容 |
| 右端 `▾` 箭头 | 提示可以下拉展开 |

**点胶囊（或点箭头）**：下方会拉出一块台词框，把当前内容完整显示出来（最多六行）。再点一下收起；**它念完那句后会自动收回**，不用手动关。

**点头像**：开关通话。通话中拖动胶囊仍然可以挪位置。

::: warning 需要开启悬浮窗
通话依赖悬浮窗显示字幕，请先在「设置 → 权限与后台 → 无障碍与悬浮窗」里打开开关，否则悬浮窗不会出现（通话本身仍可进行）。
:::

## 朗读 AI 回复

两种方式：

**手动念单条**：AI 回复气泡下方的操作栏里有个**喇叭图标**，点它念这一条，再点一次停止。正在念的那条图标会变成停止样式。

**自动朗读**：打开「设置 → 模型与用量 → 默认与专用模型」里的**自动朗读**开关，之后每条回复都会自动念。

- **边回边念**：它是攒够一整句就开口，不是等回复写完才开始，所以第一句会来得很快；
- **新回复打断旧朗读**：连续发几条时，后一条开口会自动掐掉前一条的尾巴；
- 开关关着的时候不会缓存文本，中途打开不会把之前攒下的旧回复一次念完。

## 配置语音合成（TTS）

「设置 → 模型与用量 → 默认与专用模型 → 语音合成模型」里选择供应商、模型与音色。

**不配也能用**：没有配置云端合成模型时，朗读会自动改用**手机自带的语音引擎**，零配置就能出声，代价是音质和断句不如云端。系统自带引擎也不可用时才会提示「手机上也没有可用的语音引擎」。

## 常见问题

**点了麦克风没反应**
检查「设置 → 软件权限 → 麦克风」是否已授权。

**说话没被识别**
先看有没有「录音近乎静音」的提示，有则是没录到声音（凑近说、检查麦克风是否被占用）；没有提示但识别为空，多半是识别模型没配且本地识别不可用。

**它只出声不说话，或只说话不出声**
通话是「听」和「说」两条独立的链路，可以分别排查：不出声看 TTS 配置（或直接用系统引擎），听不到你说看麦克风与识别。

**朗读念到一半断了**
正常现象：新一轮回复开口或你点了停止都会打断当前朗读。

# 语音通话、朗读与唤醒

语音功能从输入栏的**麦克风按钮**开始：轻点它进入**语音通话**，全程免手，AI 边说边听，适合不方便看屏幕的时候。想连手都不用抬，就在设置里打开**语音唤醒**，喊一声「小染小染」即可。

此外 AI 的每条回复都能**念出来**（朗读），可以手动点，也可以让它自动念。

::: tip 首次使用
语音输入的识别模型在此指定，但该入口**当前 UI 未开放**（输入栏麦克风只开关语音通话）；没配时理论上有本地识别回退，准确率与速度都差一些。朗读则优先走你配置的语音合成模型，没配时会用手机自带的语音引擎念。
:::

## 语音通话（轻点开关）

**轻点**麦克风按钮即开启通话，通话中图标会变成主题色。再轻点一次结束。

开启后进入**免手循环**：

1. 它开始听你说话（小染头顶会出现一圈紫色光环，表示正在听）；
2. 你说完停顿一下，它自动把这句话发出去，不用点发送；
3. AI 回复时**一边生成一边念**，不用等整段写完；
4. 念完继续听下一句。

**它不会自己挂断** —— 要结束就再点一次麦克风按钮。

### 小染气泡上的字幕

通话期间小染会一直显示，字幕就在她头顶的气泡里，谁在说就显示谁的话（它念到哪句显示哪句，没有就显示你正在说的内容）。她的光环表示通话状态：常亮是待命，随她说话脉动就是在开口。

**长按她的头部**唤出环形菜单，上面的「通话」按钮就是开关通话；通话中仍可拖动她挪位置。详见[小染](/guide/pet)。

::: warning 需要开启悬浮小染
通话依赖她显示字幕，请先在「设置 → Aharou 助手 → 小染」里打开「显示小染」，否则字幕不会出现（通话本身仍可进行）。
:::

## 语音唤醒（喊一声就行）

打开「设置 → AI 配置 → 默认模型」里的**语音唤醒**开关，就不用每次去点麦克风了：直接喊「小染小染」，她应一声「我在，有什么需要我做的吗？」，接下来正常说就行。

也可以一口气说完 —— 「小染小染，帮我打开抖音」—— 她会直接去办，不再多问那一句。

**用完自动回到等唤醒**：要是她应了之后你半天没出声（默人 10 秒），她就自己结束这次聆听，回去听唤醒词，不会一直开着麦克风等。

**想主动说话的时候不用喊**：点输入栏的麦克风按钮、或桌宠径向菜单里的麦克风，唤醒常驻时它们**不会把监听关掉**，而是直接开始一次聆听，说完自己回听唤醒词。要彻底关掉唤醒，去设置里关那个开关。

**她能办的事跟打字说是一样的**，语音只是换了种说法。另外多了一件专为语音准备的事 —— **打开应用与起导航**，不用你点屏幕：

- 「小染小染，打开抖音」
- 「小染小染，导航到天安门」（默认驾车，也可以说走路、坐公交）

导航用的是你手机里**已经装好的地图**，不需要在 Aharou 里配任何地图账号：装了高德走高德、装了百度走百度，两个都没装就交给系统地图让你挑。目的地直接说地名就行，不用报经纬度。

::: warning 麦克风会一直开着
开了唤醒之后，麦克风由 Aharou 的前台服务常驻监听（通知栏会一直有一条「语音唤醒」，系统状态栏也会显示录音指示），耗电比平时多一些。系统内存紧张时它可能被清掉，重新进一次 App 就会恢复。

唤醒词由本机一个小模型（约 3 MB）在本地判断，常驻期间听的音频**不会传出去**。
:::

**打不开、或听不到你说话时**，她会用语音告诉你缺什么、去哪儿开 —— 常见的是没给麦克风权限、语音模型没释放，或者要用「打开应用」却还没装好 Shizuku / 没给 root 权限。

**默认不开**：不想要麦克风常驻就让它关着，语音通话照样能用。

## 屏幕助手浮层（长按唤起）

把 Aharou 设为系统的数字助手之后，在**任何应用里**长按电源键（或系统的主屏助手手势，依机型而定）就会在底部弹出一张小卡片，可以就着**你正在看的屏幕**直接提问。

设置位置：**设置 → AI 配置 → 默认模型 → 设为系统语音助手**，点「去设置」在系统里把助手选成 Aharou。

**卡片上会显示什么**：顶部写着「正在看：应用名」，说明这次唤起来自哪个应用；问了之后，问题和回答都在卡片里实时出现。

**屏幕内容怎么带**：

- **带上屏幕文字**（默认开）：把当前屏幕上看得见的文字一并交给 AI，比如让它在商品页里挑参数、在聊天窗口里帮你措辞。密码框之类的内容会被跳过。
- **带上屏幕截图**（默认关）：额外附一张截图，AI 才能看懂画面（图表、照片、游戏界面）。截图是整屏画面，会整个离开设备，所以默认不开。

两个开关都在「设为系统语音助手」正下方。关掉文字也照样能对话，只是 AI 不知道你正看着什么。

**聊几句就走**：卡片是「问一句就走」的定位。想接着长聊，点右上角**在聊天里打开**，刚才那轮对话已经在「最近聊过的会话」里，完整的聊天界面能接着说。

**从下拉磁贴唤起**：通知栏快捷设置里有一块「Aharou 助手」磁贴（部分系统需要先拖到可见区域），在任何界面下拉点它也能弹出同一张卡片。

**快捷动作**：卡片里输入框上方有一排按钮——**提取文字**（把屏幕上的字原样拓出来）、**翻译**（中文↔英文）、**识别图片**（描述画面与关键信息）。点一下就把当前屏幕发过去，不用自己打字。这三个动作靠当前屏幕截图，所以需要配置支持图片输入的模型；截图与文本由 Shizuku 现场抓取，不需要开无障碍。

**长按电源键唤起（需要 Shizuku）**：在「Aharou 助手 → 数字助理」里打开「长按电源键唤起」后，按住电源键约 0.4 秒就会弹出卡片，看到卡片直接松手即可——不到系统的长按时限，所以小布/关机页不会出来。短按电源照常熄屏。

它靠 Shizuku 用 `getevent` 监听电源键（普通应用读不到输入设备），所以要保持 Shizuku 在运行；关机重启后需要重新在设置里打开，或者打开一次 Aharou 让它自己恢复。

::: tip 长按电源键不归我们管
部分系统（如 ColorOS）把长按电源键直接绑给了自带语音助手，这个入口第三方应用拿不到，跟「默认数字助理」设成谁无关——设成本应用也只能接到系统主动发起的助手请求。上面的长按方案是轮询按键事件实现的，并没有接管系统的那条路径。
:::

**常见情况**：

- 有些应用不给系统交出屏幕内容，卡片会提示「这个应用没把内容交出来」，不影响提问；
- 系统设置里可能还有一项「允许助手截屏」，没开就只能拿到文字；
- 部分国产系统只允许自家应用当数字助手，这种情况下开关设不上，桌面小染和语音通话仍然照常可用。

::: tip 隐私
屏幕文字与截图只随你这一条消息发出，不会存成长期记忆。截图用完即丢，关掉卡片就会释放。
:::

## 朗读 AI 回复

两种方式：

**手动念单条**：AI 回复气泡下方的操作栏里有个**喇叭图标**，点它念这一条，再点一次停止。正在念的那条图标会变成停止样式。

**自动朗读**：打开「设置 → AI 配置 → 默认模型」里的**自动朗读**开关，之后每条回复都会自动念。

**离线语音模型**：语音识别用的模型**不随安装包内置**，首次用到时自动下载（三份合计约 400MB，走国内 cnb 镜像，GitHub 兜底），下载后识别全程离线。「设置 → AI 配置 → 默认模型」最下面一行显示它当前的状态：

- **已就绪** —— 模型完整，直接能用。
- **未下载** —— 点右边的**下载**开始下载，下载中会显示进度。
- **缺失 / 大小不符（文件名）** —— 磁盘上的模型不完整（一般是以前下载中断）。点**下载**重新下载一份覆盖掉坏的，点完不用重启。
- 下载源是国内的 cnb 镜像，失败会自动退到 GitHub 原链（GitHub 对国内限速很厉害，一般走不到那一步）。

- **边回边念**：它是攒够一整句就开口，不是等回复写完才开始，所以第一句会来得很快；
- **新回复打断旧朗读**：连续发几条时，后一条开口会自动掐掉前一条的尾巴；
- 开关关着的时候不会缓存文本，中途打开不会把之前攒下的旧回复一次念完。

## 配置语音合成（TTS）

「设置 → AI 配置 → 默认模型 → 语音合成模型」里选择供应商、模型与音色。

**不配也能用**：没有配置云端合成模型时，朗读会自动改用**手机自带的语音引擎**，零配置就能出声，代价是音质和断句不如云端。系统自带引擎也不可用时才会提示「手机上也没有可用的语音引擎」。

## 常见问题

**点了麦克风没反应**
检查「设置 → 权限与后台 → 软件权限 → 麦克风」是否已授权。

**说话没被识别**
界面若提示「没听清，再说一次」，是没录到声音（凑近说、检查麦克风是否被占用）；没有这个提示但识别为空，说明识别没拿到结果（当前语音输入入口未开放，一般不会遇到）。

**它只出声不说话，或只说话不出声**
通话是「听」和「说」两条独立的链路，可以分别排查：不出声看 TTS 配置（或直接用系统引擎），听不到你说看麦克风与识别。

**朗读念到一半断了**
正常现象：新一轮回复开口或你点了停止都会打断当前朗读。

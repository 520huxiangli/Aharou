# 连接器

> 已收进「设置 → AI 配置 → 扩展」统一入口：在扩展页选「连接器」分类，点「管理」即可回到本页。

连接器是 App 内置的一份**远程 MCP 服务目录**，收录了 75 个常用的文档、代码托管、协作、云服务等，可一键接成 AI 可调用的工具，免去手写服务器地址与请求头。接入后它会出现在「设置 → AI 配置 → MCP」里，和其它 MCP 服务器一起管理。

入口：「设置 → AI 配置 → 连接器」。目录内容是内置的、不联网，只收录**远程 HTTP** 类型的常用服务；本地 stdio 服务器仍需到 MCP 页面自己添加。

## 目录页

- 顶部搜索框按名称或简介过滤。
- 按分类分组展示：协作、沟通、文件、开发、数据、设计、支付财务、搜索、其它。
- 每行左侧是品牌色首字母圆标，中间是名称与一句话简介，右侧有：
  - 一个「查看文档」外链图标，跳到该服务的官方接入文档；
  - 一个状态标签：**未接入** / **已接入** / **已禁用**。
- 没有匹配结果时显示「没有匹配的连接器」。

## 四种接入方式

点一条连接器，会按它要求的鉴权方式分流：

| 方式 | 你会看到什么 | 你要做什么 |
| --- | --- | --- |
| 直接可用（免鉴权） | 点一下即接入 | 无需任何输入 |
| 一键授权（OAuth）| 弹出授权面板，跳到服务方登录页 | 用你的账号登录并同意授权，完成后自动接入 |
| 自建 OAuth 应用 | 弹出表单，给出**回调地址**与「前往开发者后台」入口 | 到服务方开发者后台创建一个 OAuth 应用，把回调地址**原样**填进去，再把 **Client ID**（部分服务还要 **Client Secret**）粘回来，点「开始授权」 |
| 粘贴密钥 | 弹出密钥输入框，提示密钥会写进哪个请求头或 URL 参数，以及到哪去申请 | 把 API Key / PAT 之类的令牌粘进来，点「接入」 |

::: tip 密钥存在哪
密钥不会写进配置，而是存进「凭据库」；配置里只留一个 <code v-pre>{{vault:名称}}</code> 占位符，建立连接时才还原真值。详见[凭据库](/guide/vault)。
:::

## 管理已接入的连接

再点一次已接入的条目，会打开管理弹层：

- **启用连接**开关：临时停用或启用，不影响已保存的凭据。
- **移除**：删掉这条连接的配置**和**它保存的凭据（会二次确认）。移除后想再用，重新走一遍接入流程。

## 出错怎么办

- **一直连不上 / 状态报错**：多半是密钥无效或已过期。先点行内「查看文档」核对服务方对令牌的要求，再到「凭据库」删掉同名项后重新接入。
- **OAuth 授权卡住或报错**：检查「回调地址」是否一字不差地填进了厂商后台——不同服务对回调地址的校验很严。
- **不知道该填哪种令牌**：看接入表单里的提示，它会写明密钥会写进哪个请求头或 URL 参数，以及到哪申请。

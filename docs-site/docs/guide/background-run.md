# 后台运行

「设置 → 权限与后台 → 后台运行」集中管理 App 在后台的运行与提醒行为。

## 后台运行保活

开启后显示一个前台通知，避免 App 退到后台时进程被系统杀掉。即使没有任何终端会话、AI 也空闲，进程同样保持存活；进程被系统回收重建后会自动恢复这个常驻状态。点通知可以回到 App 主页。

跑编译这类长任务前建议打开。

::: tip AI 执行期间会自动保活
就算这个开关是关的，AI 开始执行任务时也会自动亮起同一个常驻通知并保持 CPU 唤醒（避免熄屏后回复断在一半、工具卡住），所有会话的任务都结束后自动收起。手动打开开关的意义在于“空闲时也常驻”：想让终端里自己跑的后台命令不被打断，就把它开着。开关开着时，AI 任务结束不会把它关掉。
:::

## 屏幕常亮

开启后只要 App 停留在前台，屏幕就不会自动息屏，适合盯着 AI 干活或看终端输出。切到其它 App 或回桌面后自动失效，不影响系统的自动锁屏设置，也不需要额外授权。

长时间开着会多耗电，插着充电器用更合适。

## Agent 完成通知

开启后，当 App 在后台、AI 完成一轮对话时会弹系统通知（标题「任务完成」，内容是你发的那条消息；如果是后台任务触发的自动轮次，显示对应的任务标题），点通知回到 App 看结果。

App 在前台时不弹，避免打扰你正在看的对话。

::: tip Android 13 及以上
首次开启上面两个开关时会先申请「通知」权限。如果系统弹不出授权框（权限之前被关过或拒绝过），会有弹窗提示，点「去设置」跳到系统设置页手动开启。权限授予前开关不生效。
:::

系统权限（安装未知应用、存储、电池优化、自启动、Shizuku）见[软件权限](/guide/app-permissions)。

## 切到后台后断网怎么办

把 App 切到后台一段时间后，AI 对话可能中断并提示「网络连接断开」。这是 Android 为省电对后台应用的正常限制：应用不在前台时，系统会**冻结**它的进程，冻结期间收不到也发不出数据，已经建立的网络连接也会被切断。这与屏幕是否熄灭无关。

**注意**：把系统的省电策略改成「无限制」通常解决不了这个问题——它只解除「低电耗 / 应用待机」限制，管不了进程冻结；而且屏幕没熄时系统根本不会进入低电耗，改它也看不出效果。

按下面的顺序设置，多数情况都能明显改善：

1. **打开上面的「后台运行保活」**，并保留通知栏的常驻通知（不要关掉它）。
2. **在多任务界面给本应用加锁**（各机型操作见下）。开了「后台运行保活」后，即使任务卡片被系统清理，保活也不会自己退出；但加锁能减少系统回收进程的概率。
3. **在系统设置里把本应用设为「无限制 / 不优化」，并允许自启动**。

### 常见品牌设置路径

不同品牌的后台与省电入口位置不同，找不到时可在系统设置顶部搜索「自启动」「后台」「省电」等关键词。

| 品牌 | 关键路径 |
| --- | --- |
| 华为 / 荣耀 | 应用启动管理 → 关闭自动管理 → 在「手动管理」里打开「允许自启动」「允许关联启动」「允许后台活动」；多任务卡片下拉加锁 |
| 小米 / Redmi | 省电与电池 → 右上角设置 → 应用智能省电 → 选本应用 → 无限制；应用设置 → 授权管理 → 自启动管理；多任务长按卡片加锁 |
| OPPO / 一加 / realme | 应用 → 应用管理 → 本应用 → 电池使用情况 → 允许后台活动；应用 → 自启动；电池 → 更多设置 → 优化电池使用 → 不优化；多任务卡片加锁 |
| vivo / iQOO | 应用与权限 → 权限管理 → 所有权限 → 自启动；电池 → 后台耗电管理 → 允许后台高耗电；多任务卡片加锁 |
| 三星 | 电池和设备维护 → 电池 → 后台使用限制 → 把本应用加入「从不休眠」；应用程序 → 本应用 → 电池 → 不受限制 |
| 原生 Android 等 | 电池 → 电池优化 → 本应用 → 不优化；若熄屏也断，WLAN → 高级 → 休眠状态保持 WLAN 连接 → 始终 |

各品牌路径会随系统版本变化，以手机实际界面为准。

### 还有几个可能原因

- 有的系统会在省电策略之外，**单独限制后台应用的联网**，请确认本应用未被禁止后台联网。
- 手机开机两三天后后台管理会变严，此时重启一次手机往往能明显改善。
- **AI 长回答在后台中断属于可预期情况**：模型长时间没有输出时，网络中间的网关可能把空闲连接断开，这一点 App 无法完全避免；回到前台后会自动重试。

# 三种模式：Build / Plan / Auto

输入框左侧的模式按钮点一下循环切换：BUILD → PLAN → AUTO → BUILD。三种模式的区别是 AI 的**权限范围**。

## BUILD（构建模式）

默认模式，功能完整。AI 可以写文件、改代码、执行构建命令，但每次需要授权的操作都会弹窗问你。

日常开发用这个。被内置安全防护拦下的高危命令（如 `rm` 根目录），AI 可带 `elevate: true` 重试，转由你一次性授权（见[工具授权](/guide/permissions)）。

## PLAN（计划模式）

进入这个模式后，AI 的写操作权限会被底层直接拦截禁用（工具层拦截，而非仅靠提示词约束）。AI 只能读取代码、检索文件并构思方案，无法修改任何文件或执行写操作命令。

适合这些场景：

- 你还不确定怎么改，想先让 AI 探索代码库、出个方案。
- 改动涉及多个文件或架构决策，想先看计划再决定。
- 你只想问问题、了解现有实现，完全不想它动手。

方案讨论清楚后切回 BUILD 再动手。

## AUTO（自动模式）

权限全放行。所有工具调用（写文件、执行命令、终端操作）自动批准，不弹任何授权窗。

::: danger 这个模式权限极大
只有灾难性删除（比如 `rm` 根目录或系统目录）以及无法静态判定的疑似破坏性命令仍会被拦截，其余一律放行（可在「设置 → 权限与后台 → 工具授权」中开启「禁用安全拦截」取消这层兜底；AI 也可带 `elevate: true` 重试，届时会弹窗要你一次性授权）。适合你已经清楚知道风险、希望 AI 全自动跑批量任务的场景。不熟悉的项目或者不确定 AI 会干什么的时候，别用这个。
:::

## AI 自己也能请求切换

除了你手动点按钮，AI 也可以主动请求进入或退出 PLAN 模式，你在界面上一键批准即可。比如它在 PLAN 模式下做完方案，会申请退出 PLAN 开始实施——退出后自动回到进入 PLAN 之前的模式。

有一个方向上的限制：**AUTO 模式只能你自己手动进入**，AI 无法通过工具切进 AUTO。但反过来，处于 AUTO 模式时 AI 可以主动切到 PLAN——这是 AI 退出 AUTO 的唯一路径。

## 退出 PLAN 会回到进入前的模式

PLAN 是临时状态：进入 PLAN 时会记下当时的模式，退出时自动恢复。从 AUTO 进入 PLAN，计划做完退出后回到 AUTO；从 BUILD 进入 PLAN，退出后回到 BUILD。不会再一律落回 BUILD。

注意：退出 PLAN 仍需你在计划审查面板上批准（点「批准并实施」），批准后模式才真正恢复。

## 运行中也能切换

模式按钮在 AI 正在执行任务时同样可用。你在 AI 干活的过程中切换模式，它会**当轮立即生效**：AI 会收到一条模式切换通知，手头任务从那一刻起按新模式处理（例如你中途切到 AUTO，后续操作就不再逐次弹窗；切到 PLAN，后续写操作会被拦截）。不需要等它这一轮跑完。

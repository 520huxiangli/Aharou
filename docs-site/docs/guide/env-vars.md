# 环境变量

「设置 → 更多 → 环境变量」可以定义全局环境变量，它们会注入到**容器内启动的所有进程**：终端、Agent 与子代理执行的命令、面板脚本、MCP 的 stdio 服务器、Git 操作。

值保存时即加密（AndroidKeyStore + AES-256-GCM，密钥与设备绑定），列表里默认打码显示。换机或清除数据后旧密文解不开，需要重新填。

## 添加与编辑

- 名称只能用字母、数字、下划线，且不能以数字开头；不能重名。
- `PROOT_TMP_DIR`、`PROOT_LOADER`、`PROOT_LOADER_32`、`PROOT_NO_SECCOMP`、`LD_PRELOAD`、`LD_LIBRARY_PATH` 是容器的关键变量，不允许占用。
- 「敏感值（列表打码显示）」默认勾选，只影响列表里的显示，值本身始终加密存储。
- 变量名就是主键，**编辑时改不了名**，要改名只能删掉重建。
- 修改只对**之后新启动**的进程生效，已经开着的终端不受影响。

## 优先级

同名变量出现多次时，靠后的覆盖靠前的：

1. 全局环境变量（本页）
2. 容器自己的环境变量（「容器与镜像」里按容器配的）
3. 具体调用方传入的变量（例如某个 MCP 服务器自己的 `env`）

## 别和另外几套环境变量搞混

界面上有四套长得很像的东西，其实各管各的：

::: v-pre
| 哪一套 | 在哪配 | 管什么 |
| --- | --- | --- |
| 全局环境变量（本页） | 设置 → 更多 → 环境变量 | 容器内启动的所有进程 |
| 容器环境变量 | 设置 → 更多 → 容器与镜像 | 只对该容器镜像的启动生效 |
| 面板脚本参数 | 设置 → AI 配置 → AI 供应商 → 某个供应商的「面板脚本」 | 以 `AICODE_KEY_<名称>` 注入面板脚本，额外支持 `{{PROVIDER_API_KEY}}` 等占位符；脚本路径本身也可经配置通道读写（`providers.<id>.panel_script`） |
| MCP 服务器 env | 设置 → AI 配置 → MCP | 只注入该 MCP 的 stdio 进程 |
:::

本页这套**没有任何内置变量**，初始是空的；也不会做占位符替换，写什么就是什么。

# 人格（Soul）

「设置 → Aharou 助手 → 人格 (Soul)」用来定义助手的名字、图标、说话风格和人格正文。这些内容会拼进 AI 的系统提示词，名字与图标还会显示在每条回复上方。

人格是**全局的**，所有项目、所有会话共用一份，存在 `SOUL.md` 里（容器内的路径是 `/root/.aharou/memory/SOUL.md`）。

## 可以改什么

| 字段 | 说明 |
| --- | --- |
| 名字 | 默认 `Aharou`；显示在回复上方的身份行，也注入系统提示词 |
| 图标 | 选 emoji、从相册选图（会裁成正方形并压缩，太大的图会提示换一张），或「用默认图标」（✨） |
| 风格 | 一句话的说话风格约束。如果这里规定了回复语言，会覆盖「跟随用户语言」的默认规则 |
| 语言 | `自动`（跟随用户语言，不加额外约束）/ `中文` / `English`——后两者会作为硬约束写进系统提示词（1.14.2 起） |
| 人格正文 | 性格与说话方式的正文，写清它会注入系统提示 |

正文有长度限制：中文占多数（CJK 字符超过三成）时最多 **1600 字**，否则按英文算最多 **1000 词**。超限时计数器变红、「保存」点不动。

## 生效时机

- 点「保存」后，聊天里的名字与图标**立刻**更新，不用重启；
- 系统提示词里的名字、风格、正文在**你发下一条消息**时重新读取，同样不用重启。

「恢复默认」只是把编辑区换成默认模板，**不点保存不会写盘**；有未保存改动时页面会提示「有未保存的修改」。

## 说明

- 人格只注入**主代理**，子代理不带。
- 正文有注入防护：出现「ignore / disregard / forget … previous instructions」这类句式时，走配置通道写入会被直接拒绝；构建系统提示词时，这些行也会被逐行丢掉（设置页保存不做这项检查，但注入时同样会过滤）。
- 人格随「备份与还原」里的记忆一起打包，换机后记得恢复回去。

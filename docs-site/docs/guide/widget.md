# 桌面小组件

把 Aharou 的快捷入口和最近会话放到手机桌面，不用先点开 App。

## 添加与移除

长按桌面空白处 → 打开「小组件 / 微件」→ 找到 Aharou → 把「**快捷入口与最近会话**」拖到桌面。

- 建议占 4×2 格；可以横向、纵向拉伸，但格子太小会显示不全。
- 不需要时，像删除普通图标那样把它拖到「移除」即可。

不同手机这个入口的名称略有差别，一般在「小组件」「微件」或长按桌面后的「添加到主屏幕」里。

## 上面有什么

顶部是三个快捷按钮：

- **新建对话**：开一个新会话并进入聊天页。
- **打开聊天**：打开 App，回到聊天页。
- **语音通话**：进入 App 后直接开启语音通话。

下面是最多五条**最近更新的会话**（跨工作区，不含子代理会话），每条显示会话标题和相对时间（如「5 分钟前」）。点一条直接进入该会话。一条都没有时显示「暂无最近会话」。

## 刷新与配色

- 组件在**添加到桌面、设备重启、App 更新**时自动刷新，此外每 **30 分钟**再自动刷新一次（这是系统允许的最短周期，App 不做常驻后台刷新）。
- 配色跟随 App 当前外观（预设配色 / 莫奈取色 / 明暗模式）自动匹配。
- 同一个桌面上可以放多个组件实例，各自独立，点开的会话也互不影响。

## 看不到内容或更新不及时

- 组件里的会话来自 App 本机保存的聊天记录；还没聊过时自然是空的，聊过之后会在下一次刷新时出现。
- 想立刻看到最新会话，把组件删掉重新添加一次，会立即刷新。
- 这里只列**最近活跃**的几条；很久没聊的会话不在这里，进 App 从侧边栏会话列表里找。

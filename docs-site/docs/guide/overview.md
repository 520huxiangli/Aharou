# 功能总览

本页作为使用手册的快速导览索引，整理了主界面核心工作流与设置页各功能入口对应的文档。

本索引按**功能主题**归组，与设置页里的实际分组不完全对应：例如「无障碍」与「悬浮窗」在设置中是「权限与后台」下的两行独立设置，「配置审计」与「人格（Soul）」在「Aharou 助手」分组，「记忆」在「数据与诊断」，而「自定义提示词」没有独立设置入口，属于文件式配置。

::: tip 版本说明
标了版本的条目（如「v1.11.0-dev 起」）表示该功能自该版本起引入。
:::

## 核心工作流与主界面

| 功能 | 说明 |
| --- | --- |
| 聊天交互与工作区 | 标题栏、侧边栏、工具栏、消息队列、长文本粘贴折叠、工作区切换 → [文档](/guide/chat) |
| 运行模式（三种模式） | Build / Plan / Auto 的权限控制与场景 → [文档](/guide/modes) |
| 检查点与撤销 | AI 修改前自动快照，支持一键安全回滚 → [文档](/guide/checkpoint) |
| 终端交互 | 多标签会话、辅助按键栏、配色与字体设置 → [文档](/guide/terminal) |
| 语音通话与朗读 | 免手语音通话与悬浮窗字幕、AI 回复朗读与自动朗读（语音输入已下线，输入栏麦克风只做通话开关）→ [文档](/guide/voice) |
| 内置浏览器 | WebView 浏览器，支持 AI 自动化操作网页（导航、点击、填表、截图等）→ [文档](/guide/browser) |
| 文件浏览与代码编辑 | 缩进树形目录、语法高亮、内置代码编辑器（v1.11.0-dev 起），以及工作区文件在手机上的位置与访问 → [文档](/guide/files) |
| Git 版本管理 | 可视化状态管理、分支切换、提交历史、回退与删除（v1.11.0-dev 起）→ [文档](/guide/git) |
| 平板与大屏适配 | 响应式分栏、常驻侧边栏、并排双栏工作台（v1.11.0-dev 起）→ [文档](/guide/tablet) |

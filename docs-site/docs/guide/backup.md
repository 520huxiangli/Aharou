# 备份与还原

「设置 → 备份与还原」可以把应用配置、聊天记录、记忆与灵魂和工作区文件导出成一个加密压缩包，也能从备份还原回来。

## 导出

页面上方勾选要导出的范围，共八项：AI 供应商、连接与同步、聊天记录、MCP 服务器、授权规则、应用设置、工作区文件、记忆与灵魂。勾选状态会记住，下次进来沿用。

其中的**记忆与灵魂**打包 `aharou-global/memory` 下的全部文件（`SOUL.md`、核心档案、全局记忆、每日日志、facts 等）。

其中**工作区文件默认关闭**，需要时手动打开。它会打包所有本地模式的内部工作区文件，包含 `.git` 目录，所以仓库历史和未推送的提交都能完整还原。通过「添加本地目录」加进来的外部工作区属于你设备上的原始目录，不会被打包。排除规则是各工作区自己的 `.gitignore` 加上同步功能的默认忽略清单（`node_modules`、`build`、`dist` 等），符号链接不备份。

::: tip 代码优先用 Git 备份
Git 仓库本身就完整保存了代码和历史，这里的导出更适合作为额外的备用手段，而不是主要的代码备份方式。
:::

点「导出备份」后会弹窗设置口令：

- **填了口令**：用 AES-GCM 加密。
- **留空**：输出明文 tar.gz。

导出的包里含 API Key 等凭据，通过系统文件选择器保存到你指定的位置。

::: danger 务必牢记加密口令
加密备份在遗失口令时无法解密恢复，没有任何后门或找回途径。
:::

## 导入

从备份文件还原，采用**合并方式**，不会清除现有数据。需要输入对应的口令，未加密的备份留空即可。

如果备份里含工作区文件，会先弹出「恢复工作区」选择弹窗，列出备份中的每个工作区（名称和文件数），你可以勾选要恢复哪些。

::: warning 恢复工作区会直接覆盖
勾选的工作区会覆盖本地同名工作区里的文件，且无法撤销。本地没有同名工作区时会自动新建一个再写入，所以换新设备或重装后不会丢数据。远程模式的工作区（文件在服务器上）不参与还原。
:::

导入完成后会显示还原数据的汇总清单：供应商、远程连接、远程挂载、聊天会话、聊天消息、待办项、MCP 服务器、全局授权规则、工作区文件、记忆文件各恢复了多少；末尾还会补一句「主题、保活、日志、识图、同步偏好已覆盖」。

聊天会话会按备份时的所属工作区归位：本地有同名工作区直接还原过去，没有同名工作区时会自动新建一个空工作区再挂入会话（与「恢复工作区」自动新建的逻辑一致），换设备或重装后各工作区的会话不会挤到同一处。

## 一点说明

备份口令只作用于导出的备份文件本身。应用内部存储的 API Key、连接密码、SSH 私钥等敏感配置另由系统密钥库（Android Keystore）加密保存，与备份口令相互独立；换设备时请通过备份导入迁移，直接拷贝应用数据目录会因密钥不匹配而无法解密。

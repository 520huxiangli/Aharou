# 无障碍与悬浮窗

这两个设置都在「设置 → 权限与后台」下，管的是两件不同的事：无障碍让 Agent「看得懂、点得动」屏幕；悬浮窗让它在后台干活时留个看得见的提示。

## 无障碍

开启后 Agent 可以读取界面元素、截图、点击与滑动——也就是能在别的 App 里替你动手。

但写动作有明确限制：`tap` / `swipe` / `key` / `setText` **只用于 Aharou 自己的界面**；当 Shizuku 已就绪、而且前台跑的是第三方 App 时，这些写动作会被直接拒绝并提示改用[影子屏](/guide/shadow-screen)（vscreen）——主屏留给你，不去抢你的操作。只读动作（`dump` / `find` / `shot` / `windows` / `foreground`）不受这个限制，随时可用。

Android 不允许应用自行开启无障碍，必须你手动勾选：

1. 「设置 → 权限与后台 → 无障碍」→ 点「去系统设置开启」跳到系统的无障碍页；
2. 在列表里找到「Aharou 无障碍」并勾选；
3. 回到 App 点「刷新状态」，出现「已开启 · 已连接」即可。

状态有三种：

| 状态 | 含义 |
| --- | --- |
| 已开启 · 已连接 | 服务在跑，Agent 可以操作 |
| 已开启 · 未连接（系统可能稍后重绑） | 系统认为开着，但服务还没绑上；等一会儿或重新勾选一次 |
| 未开启 | 还没勾选 |

Agent 用的工具是 `a11y`，动作有 `dump`（读界面元素树）、`find`、`tap`、`swipe`、`key`（支持 back / home / recents / notifications）、`shot`（系统截图，需要 **Android 11 及以上**）、`setText`、`windows`、`foreground`。默认**每次调用都会弹确认框**（「确认无障碍操作」），弹窗里有三个选择：拒绝 / 允许（仅本次）/ **始终允许**。点「始终允许」会在当前项目记住一条规则（整个 `a11y` 工具的调用都放行），之后就不再弹框。

用的时候留意：

- 无障碍给出的节点 id **会过期**，点之前最好重新 `dump` 或 `find`；
- `dump` 最多返回 400 个节点、深度到 25 层，超出部分不显示；
- 部分国产 ROM（如 MIUI）需要额外允许「自启动」并加入电池优化白名单，服务才稳定，见「软件权限」。

## 悬浮窗

打开「设置 → 权限与后台 → 悬浮窗」里的「启用悬浮窗」（默认关闭）之后：

- Agent 在后台干活时，屏幕上飘出一枚小胶囊，显示当前工具名与状态；
- 点一下回到 Aharou，也可以拖动摆放，位置会记住；
- Aharou 回到前台时自动隐藏。

**语音通话期间**这枚胶囊会一直显示（不受下面的显示条件限制），并变成通话字幕：头像外圈亮环表示正在听你说话，第二行显示**谁在说就显示谁的话**；点胶囊或右端的 `▾` 箭头会拉出一块台词框看完整内容，点头像则是开关通话。详见[语音通话与朗读](/guide/voice)。

显示条件要**同时满足**：Aharou 不在前台、Agent 有正在执行的任务、悬浮窗权限已授予。

- 首次打开开关会先申请「显示在其他应用上层」权限；没给的话会跳到系统授权页，开关保持关闭；
- 这个权限在「软件权限」页里也有一条，两处都能查看和授予；
- 部分国产 ROM 还需允许「后台弹出界面」并保持自启动，悬浮窗才稳定。

# 无障碍与小染

这两件事现在分在两个分组里：无障碍在「设置 → 权限与后台 → 无障碍」，小染在「设置 → Aharou 助手 → 小染」。它们管的是两件不同的事：无障碍让 Agent「看得懂、点得动」屏幕；小染是屏幕上的悬浮伙伴，Agent 的进度与通话字幕都挂在它身上（详见[小染](/guide/pet)）。

## 无障碍

开启后 Agent 可以读取界面元素、截图、点击与滑动——也就是能在别的 App 里替你动手。

但写动作有明确限制：`tap` / `swipe` / `key` / `setText` **只用于 Aharou 自己的界面**；当 Shizuku 已就绪、而且前台跑的是第三方 App 时，这些写动作会被直接拒绝并提示改用[影子屏](/guide/shadow-screen)（vscreen）——主屏留给你，不去抢你的操作。只读动作（`dump` / `find` / `shot` / `windows` / `foreground`）不受这个限制，随时可用。

Android 不允许应用自行开启无障碍，必须你手动勾选：

1. 「设置 → 权限与后台 → 无障碍」→ 点「去系统设置开启」跳到系统的无障碍页；
2. 在列表里找到「Aharou 无障碍」并勾选；
3. 回到 App 点「刷新状态」，出现「已开启 · 已连接」即可。

状态有三种：

| 状态 | 含义 |
| --- | --- |
| 已开启 · 已连接 | 服务在跑，Agent 可以操作 |
| 已开启 · 未连接（系统可能稍后重绑） | 系统认为开着，但服务还没绑上；等一会儿或重新勾选一次 |
| 未开启 | 还没勾选 |

Agent 用的工具是 `a11y`，动作有 `dump`（读界面元素树）、`find`、`tap`、`swipe`、`key`（支持 back / home / recents / notifications）、`shot`（系统截图，需要 **Android 11 及以上**）、`setText`、`windows`、`foreground`。默认**每次调用都会弹确认框**（「确认无障碍操作」），你可以在弹窗里选「允许」（仅本次）、「本次会话」「24 小时」或「始终允许」（记成规则），详见[工具授权](/guide/permissions)。

`tap` 与 `setText` 还可以带一个 `label`（手指下或目标元素的文字）：命中「确认支付」「发送」「删除」这类敏感词时，本次调用会提级为**敏感操作**，**必须逐次确认且不会被记忆**。详见[影子屏](/guide/shadow-screen)的「带 label 的敏感动作」。

无障碍这条只提供**单步**动作（读一屏、点一下、打一段字）。想让 AI 自己连着走「看屏 → 决策 → 点按 → 再看屏」多步完成任务，用[影子屏](/guide/shadow-screen)的 `task`，它在每步之间会等界面稳定再判断。

用的时候留意：

- 无障碍给出的节点 id **会过期**，点之前最好重新 `dump` 或 `find`；
- `dump` 最多返回 400 个节点、深度到 25 层，超出部分不显示；
- 部分国产 ROM（如 MIUI）需要额外允许「自启动」并加入电池优化白名单，服务才稳定，见「软件权限」。

## 小染

悬浮层只剩小染一个，原先那枚「状态胶囊」已并入她：Agent 进度进她的气泡、通话字幕也进她的气泡、通话开关进她的长按菜单。开关、权限与注意事项单独成页，见[小染](/guide/pet)。

真机运行

不用电脑，
也不用自己搭环境

所有能力在本机完成。Agent 在内置 Linux 里读文件、跑构建；影子屏让它在后台自主操作 App； 小屏幕把每一步实时可视化——终端逐行输出、网页快照、影子屏直播同屏呈现。

核心特性

08 modules
01

内置 Linux 与终端

Alpine（PRoot）容器 + 多标签终端，导入自定义镜像、挂载宿主目录、切换远程 SSH 后端。

$ apk add · ssh remote
02

影子屏 Shadow Screen

无头虚拟显示屏：Agent 在「看不见的屏幕」里运行、截图、操作 App，完全不打扰手机前台。

$ display :0 · headless
03

全能 AI 对话

多供应商 / 多模型无缝切换，Markdown、图片与思考过程（思维链）实时展示。

$ model · chain-of-thought
04

小屏幕实时监控

工具执行实时可视化：终端逐行输出、网页快照、影子屏直播同屏呈现。

$ tail -f · snapshot · live
05

智能浏览器面板

内置浏览器，Agent 自主驱动打开页面、点击与操作，完成端到端任务。

$ open url · act · scrape
06

沙箱文件与预览

文件浏览器与预览：图片 / 文本 / Markdown / 音频 / 视频 / PDF / APK / 压缩包。

$ ls -la · preview
07

Shizuku 与加密变量

经 Shizuku 在系统层执行命令、读写其它应用目录，无需 root；环境变量加密存储自动注入。

$ shizuku · export KEY=***
08

人格引擎与开放生态

SOUL.md 定义名字 / 图标 / 语言 / 人格，随手改即时生效；MCP、技能、子代理自由拓展。

$ soul.md · mcp · skills

快速上手

5 分钟跑起来

01

安装与初始化

下载对应架构 APK，允许「安装未知应用」后安装。首次启动自动初始化内置 Alpine 环境。

02

配置模型与 API Key

填入你自己的模型端点与 API Key，支持任意 OpenAI 兼容供应商，密钥仅本机加密存储。

03

激活 Shizuku（可选）

经无线调试启动 Shizuku，Agent 即可在系统层执行命令、读写其它应用目录，无需 root。

04

编写 SOUL.md 人格

定义名字、图标、语言与人格正文，保存后聊天里即时生效。
